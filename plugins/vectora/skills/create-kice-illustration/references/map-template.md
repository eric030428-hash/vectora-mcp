# 승인 세계 양식 실행

기본 world_continents 양식을 편집할 때만 읽는다. 공통 스타일·좌표·문자·검수는 [지도 공통](map-illustrations.md)에 있다.

## 자산과 대상 경로

- [world_continents.vectora](../assets/maps/world_continents.vectora)를 별도 작업 문서로 열며 기본 자산은 수정·삭제하지 않는다.
- 잠긴 ‘내부 경계 점선 합치기’ 그룹은 흰 육지·실선 해안·점선 국경이다. 아래 회색 ‘경로’는 강조용 면이며 바탕에 가려진 것이지 숨김 상태가 아니다.
- 회색 채움 `#AAAAAA`, 대지 바다 배경 `#EEEEEE`는 **이 양식의 기본값**이다. 이 양식을 그대로 활용할 때 보존하되 다른 유형의 보편 강제값으로 쓰지 않는다.
- 동일 이름 ‘경로’는 해당 지역을 확대하고 작업본에서 하나씩 드러내 윤곽·위치·본토·섬·인접국으로 확인한다. 좌표 상자/배열 순서만으로 국가를 단정하지 않는다.
- 분리 영역도 요청 범위 내 해당 부분을 함께 선택한다. 작업본에서 확인한 대상만 의미 있는 이름으로 바꾸고 임시 검수 번호는 제거한다.
- 원본 투영·좌표·경계 형상을 보존한다. 해안까지 일괄 점선으로 바꾸지 않는다. 국경만 선택할 수 없는 다른 바탕은 실제 개체 구조부터 확인한다.

## 해안과 국경의 선택 편집

작업본 잠금해제 → `inspect`로 ‘내부 경계’ 327경로와 ‘외곽선’을 분리 확인한다. 국경 없음이면 내부 경계만 숨김/제외하고, 국경 실선이면 내부 경계의 `strokeDashArray`를 제거한다. 해안 외곽은 보존하며 필요한 선은 `#000000`으로 정규화한다. 원본 자산은 유지하고 편집은 작업본에만 적용한다. 메타데이터 없는 다른 바탕은 실제 구조를 검사하며 이 개수·이름을 가정하지 않는다. 이 편집은 기존 경계의 표시 변경이며 새로운 지리 경계나 투영을 생성하지 않는다.

## 강조 및 범위 편집

- 회색 강조의 기본 조작은 확인된 국가 경로 `bringFront`다. 옆 국가나 바탕 전체를 바꾸지 않는다. 별도 색 요청은 확인된 강조 면에 적용한다.
- 강조 후 인접국·섬·해안·국경이 맞고 선이 가려지지 않는지 확인한다. 필요한 경계는 채움 없는 선으로 위에 보존하되 흰 육지 면을 다시 앞에 올려 강조를 가리지 않는다.
- 원본 좌표에서 crop 범위를 고른다. `배율 = 최종 지도 창 폭 / 선택 범위 폭`, `창 높이 = 선택 범위 높이 × 동일 배율`; 계산 단위부터 통일한다.
- 지도와 강조 면을 같은 변환으로 배치한 후 클립한다. 최종 대지는 마스크 창과 독립 라벨의 외곽으로 정한다.
- 바다색이 별도 도형 대신 대지 배경일 수 있다. 작업 대지와 불투명 JPEG 배경 설정에서도 선택한 수역색을 보존한다.

## 편집 가능한 사각 클립

- 작업본에서 잠긴 바탕을 풀고 바탕·강조 면과 맨 위 마스크 사각형을 함께 선택해 `clip`한다. 바탕이 선택에서 빠져 세계 전체가 밖에 남지 않았는지 확인한다.
- 경로를 남기는 마스크를 사용한다. 화면 밖 경로 삭제·래스터 crop·대지만 줄이는 방식으로 대신하지 않는다.
- 현재 `clip`의 마스크는 문서 좌표에 고정된다. 클립 후 그룹만 이동/축소하면 어긋날 수 있으므로 지도·마스크 변환을 같이 확인하거나 다시 클립한다.
- 그룹 전체 선택 상자가 보이는 창과 같다고 가정하지 않는다. 표시용 테두리는 별도 선으로 만들고 마스크 창에 맞춘다.
- 문자·인출선은 클립 그룹 위의 독립 요소로 둔다. 필요하면 바탕만 다시 잠그며 문자 편집은 가능하게 둔다.
