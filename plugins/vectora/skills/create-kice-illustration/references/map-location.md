# 위치·점·기호

[지도 공통](map-illustrations.md)을 먼저 적용한다.

- 원·사각·삼각·다른 기호는 위치나 범주를 구별한다. 같은 크기 기호를 근거 없이 수량 비례기호로 해석하지 않는다.
- 점은 등록된 좌표 또는 바탕에서 확인된 위치에 놓는다. 기호 중심과 위치 기준을 일치시킨다.
- 작은 장소를 타원·국지 영역으로 묶을 수 있지만 국가 전체 채움이나 자연 경계와 혼동하지 않게 한다.
- 문자·인출선·기호를 분리하고 필요한 기호 범례만 둔다. 고도 등 부가 수치는 단위와 의미를 명시한다.
- 화살촉 없는 연결선은 지점 묶음·비교·관계일 수 있다. 선이 있다는 이유로 이동 방향을 추측하지 않는다.
- 여러 점의 겹침은 기호 간격·라벨 인출선으로 해결하되 지리 위치를 조용히 옮기지 않는다.
