# 통계 지도

- 공간 단위·자료 시점·값·단위·결측을 맞춘다. 국가/행정구역을 혼용하지 않고 하위 경계가 없는데 국가 경로로 소지역 값을 대신하지 않는다. 표 행 ID와 검증 feature ID를 명시적으로 대조하고 미매칭/중복을 남긴다. 자동 join/단계구분/기호 생성/통계 갱신은 실제 지원 전 주장하지 않는다.
- 비율/밀도 단계구분은 구간 경계와 포함 조건·순서 있는 농도를 명시한다. raw 값·구간·표시 반올림을 분리하고 결측을 최저 등급으로 칠하지 않는다. 상/하위 순위 채움은 서열 통계이며 미제공 지표명을 만들지 않는다.
- 등급별 기호의 크기/명도/범례를 그대로 대응시킨다. 세 등급 원을 연속 비례 원으로 바꾸지 않는다. 총량 비례 원의 양수 값은 **r=k×sqrt(value)**로 면적을 대응시키고 지도/범례에 같은 k를 쓴다. 최소 기호·0·음수·결측 정책과 크기표를 별도로 확인한다.
- 단위점은 점 하나의 수량을 범례에 명시하며 도시 위치점과 구별한다. 장식 pattern의 점 수는 수량 보증이 아니다. 자료 해상도보다 정밀한 위치를 주장하지 않는다.
- 래스터 명암은 지표별 방향을 확인한다(인구밀도 검정=높음과 야간 빛 흰색=많음 등). 원자료·농도 방향·단위·범례를 보존한다.
- 단순 범례/수치 라벨/통계 기호는 이 하위유형 안에서 처리한다. 자체 축/구성비/수치 구조의 독립 차트는 전역 복합으로 라우팅하며 native 생성기로 기본 구조를 만든다. 비교 패널은 등급·원 크기·차트 축을 공통화하거나 차이를 명시한다.
