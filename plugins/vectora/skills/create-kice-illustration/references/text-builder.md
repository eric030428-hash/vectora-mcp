# 선택 도구: 텍스트 배경

공통/텍스트일러 원칙을 읽은 뒤 배경 자동화가 필요할 때만 사용한다. 도구는 예시 이미지나 사전 본문을 읽지 않고 입력 치수로 SVG와 빈 영역 좌표를 계산한다. 다른 매체는 직접 벡터로 구성한다.

프로젝트 루트: `node scripts/build_text_frame.mjs --spec <입력.json> --output <배경.svg>`.
모듈: `buildTextFrame(spec)` → `{svg, layout}`. 기존 파일 교체는 명시적인 `--force`일 때만 한다.

| 입력 | 의미 |
|---|---|
| variant | newspaper-wave / newspaper-band / scroll / browser / noticeboard |
| widthMm | 최종 폭, 기본 108, 도구 범위 30–108 |
| contentHeightMm | 필수. 실제 조판 높이, 지정한 상자 높이, 또는 지정 줄 수를 UND 8pt로 실제 측정한 높이. 여백 제외 |
| paddingMm | 예약한 본문 영역 바깥에 추가할 안쪽 여백. contentHeightMm에서 빼지 않음 |
| titleHeightMm / headerHeightMm | 기사 제목 / 신문명·날짜 등 상단 표시 예약 높이. 서로 다른 영역 |
| columns / cardTitleHeightMm | 게시판 열 수 / 카드 제목 높이 |
| footerHeightMm / portraitMm | 작성자 자리 높이 / 초상 자리 크기 |
| asideWidthMm / asideHeightMm | 브라우저 내부 삽화 예약 공간 |

`layout.slots`는 문서 px 좌표이며 role은 chrome/title/content/author다. `textAlign`과 `verticalAlign`을 실제 텍스트 높이에 맞춰 적용한다. `illustrationSlots`는 빈 자리이며 인물이 이미 그려진 것이 아니다. `whiteBackground:false`는 매체 표시 문자용이다.

신문은 `newspaper-wave`(하단 물결) 또는 `newspaper-band`(회색 제호 띠·직선 하단)로 구성한다. 이 배경 도구의 상단 선은 **신문명·날짜 영역의 경계**이며 기사 제목의 밑줄이 아니다. 상단 선을 본문 높이나 전체 높이에 맞춰 아래로 옮기거나 제목 아래에 선을 추가하지 않는다. `headerHeightMm`은 제호·날짜를 담는 얕은 영역이고, 기사 제목이 없는 빈 틀은 `titleHeightMm: 0`이다. 지정 내용 높이는 `contentHeightMm`에 넣는다.

도구는 제호/날짜 슬롯만 반환하며 글을 넣지 않는다. 따라서 [신문 기본 구조](text-illustrations.md#신문의-기본-구조)에 따라 `masthead` 슬롯에는 `○○신문` 또는 지정 신문명을, `date` 슬롯에는 기호 또는 지정 날짜를 별도 문자로 채운다. 빈 본문 요청에서도 이 상단 표시를 완성한다. 도구 입력에 미지원 `masthead`/`date` 필드를 넣는 대신 반환된 슬롯에 조판한다. 원문이 있는 경우의 기사 제목은 `headline` 슬롯이며 그 아래에는 여백만 둔다.

줄 수 입력은 공통 원칙대로 실제 텍스트 상자에서 측정한 mm 높이를 `contentHeightMm`에 넣는다. 이 배경 도구 자체는 글꼴·행간·줄 수를 측정하지 않으며 `lineCount` 같은 미지원 필드를 받지 않는다.

`contentHeightMm: 100`은 사용 가능한 본문 슬롯 높이 100mm를 뜻하며 `paddingMm`은 그 밖에 더한다. 너비도 지정된 경우 `layout.slots`의 실제 content 너비를 확인한다. 이 도구에는 `contentWidthMm` 입력이 없으므로 해당 매체의 외곽 너비·여백으로 계산하거나 직접 구성하고 미지원 필드를 넣지 않는다. 브라우저의 옆 삽화 등으로 영역을 나눴다면 슬롯 면적의 합이 아닌 **하나의 연속된 예약 직사각형**이 지정 크기를 수용해야 한다.

입력은 이번 원문과 목적에서 직접 작성한다. 빈 텍스트 상자를 예약하는 요청은 본문 없이 그대로 완성한다. 본문·삽화·그래프가 필요한 완성본은 모두 채우고 검수한다. 도구가 주는 장식·간격 기본값은 초기 배치값이다. **기본 배경 SVG는 원칙 충족 여부를 확인하고 필요한 부분만 보완한다.** 장식을 추가하기 전에 외곽 크기·본문 슬롯·상단 띠·프레임 경계를 확인하고, 보완 중에는 이 구도를 유지한다. 장식을 넣으려고 `headerHeightMm`·여백·외곽 크기를 키우거나 본문 슬롯을 줄이지 않는다. 이미 있는 장식 영역의 빈 곳에 들어가는 세부만 추가하고 공간이 없으면 생략한다. [그림 명암·묘사 원칙](text-illustrations.md#그림-부분의-명암과-묘사-밀도)에 맞게 넓은 장식 면은 연한 회색으로 조정하고, 필요한 작은 부분에만 진한 강조를 둔다. 매체의 부가 요소는 유지·보완하되 세부를 추가한다는 이유로 그림 전체를 어둡게 만들지 않는다. 두루마리는 [말이와 본문 폭 원칙](text-illustrations.md#두루마리의-말이와-본문-폭)을 적용해 도구 기본 말이가 두껍거나 종이가 좁으면 해당 도형을 조정한다. 원래 흰 내용 영역과 예약 치수는 최소한 유지하며, 사용자가 본문 확장을 요청하면 그 방향으로 넓힌다. 장식 부분만 선택해 수정하며 모든 흰색을 일괄 회색으로 바꾸지 않는다. 현재 입력에는 색상/아이콘 상세 설정이 없으므로 미지원 필드를 넣지 말고, 반환 SVG 또는 앱의 해당 개체를 편집한다.
