# 지도 원칙

국가·지역의 위치와 분포를 보이는 지도에 적용한다. 자연 지형의 입체도·단면도는 삽화 원칙을 적용한다. 공통 문자·저장 규칙을 함께 지키며, 복합형에서는 지도 바탕과 다른 유형의 요소를 구분한다.

## 기본 양식과 대상 확인

- 기본 자산은 이 스킬의 [world_continents.vectora](../assets/maps/world_continents.vectora)다. 사용자가 이번 작업에 별도 지도 양식을 지정하면 그것을 우선한다. **원본을 보존하고 별도 작업 문서에서 편집**한다. 생성 이미지나 새 세계지도 데이터로 승인된 바탕을 대체하지 않는다.
- 잠긴 **‘내부 경계 점선 합치기’** 그룹은 흰 육지 면·대륙/해안의 실선·국가 사이의 점선으로 이루어진 기본 지도다. 그 아래의 회색 **‘경로’**들은 국가/섬의 강조용 면이다. 회색 경로는 기본 지도에 가려져 있을 뿐 숨김 속성이 꺼진 것은 아니다. 국경을 실선으로 바꾸거나 해안을 점선으로 바꾸지 않는다.
- 국가 경로의 이름·ID·위치·윤곽을 확인한다. 이름이 모두 ‘경로’이면 필요한 지역을 확대하고 후보 경로를 검수용으로 하나씩 드러내어 식별한다. 좌표 상자나 배열 순서만으로 국가를 단정하지 않는다. 한 국가가 여러 섬/분리된 경로이면 요청 범위에 보이는 해당 부분을 함께 선택한다. 본토와 섬·인접국을 대조하고, 작업본에서 확인된 대상만 알아보기 쉬운 이름으로 바꿀 수 있다. 임시 번호·검수 표시는 최종 그림에 남기지 않는다.
- 원본의 위치·투영·국경 형상을 보존한다. 경계가 불분명하거나 요청 지역을 양식에서 구분할 수 없으면 확인이 필요한 부분을 알리며 임의의 경계를 그리지 않는다. 도시 좌표는 실제 위치를 확인하고 양식의 투영/좌표 대응이 확인된 경우에만 환산한다. 지도상의 x/y를 위경도로 가정하지 않는다.

## 회색 강조와 표시

- **회색 표시 요청의 기본 조작은 해당 국가/지역 경로를 ‘맨 앞으로 가져오기’(`bringFront`)**다. 바탕 전체의 색이나 다른 나라를 바꾸지 않는다. 양식의 회색 채움(현재 `#AAAAAA`)을 유지하며 별도 색상이 명시되면 그 요청을 따른다.
- 강조 면을 옮긴 뒤 바탕과 윤곽이 맞고, 인접국까지 칠하지 않았는지 확인한다. 작은 섬이나 국경·해안선이 강조 면 때문에 사라지지 않아야 한다. 국가를 실선 테두리로 다시 둘러 내부 점선을 대체하지 않는다. 필요한 경계만 채움 없는 선으로 위에 보존할 수 있으며 흰 육지 면을 다시 앞에 올려 강조를 가리지 않는다.
- 도시 점은 요청한 위치의 작은 검정 점으로 표시한다. 국가 지시선의 끝은 그 국가 안쪽에 닿게 하되, 요청하지 않은 도시 점을 뜻하는 검정 점/화살촉을 자동으로 추가하지 않는다. 바다·옆 나라·국경 위로 끝이 어긋나지 않게 한다.
- A·B·C, 지명, 범례는 **UND Regular 8pt·자간 -60**의 독립 문자다. 작은 나라 안에 억지로 넣지 말고 가까운 빈 바다/여백에 놓고 짧은 검정 지시선(기본 0.3pt)으로 연결한다. 다른 문자·지시선·강조 영역과 겹치지 않게 하며 대상 순서와 문자 대응을 유지한다. 이름·제목·방위표·축척 막대·위경선은 요청이나 판독상 필요가 없으면 추가하지 않는다.

## 범위, 비율과 최종 크기

1. 먼저 **보여줄 지리 범위와 최종 폭**을 정한다. 세계 전체인지 특정 지역인지, 포함해야 할 섬/국가와 가로·세로 형태를 확인한다. 지정 폭은 별도 설명이 없으면 지시 문자까지 포함한 완성 그림 폭이다. 전체 세계지도용 고정 크기를 지역 지도에 강제하지 않는다.
2. 원본 좌표에서 사각 범위를 정하고, 최종 폭에 들어갈 **지도 바탕만 동일한 X/Y 배율**로 확대·축소한다. 전체 세계는 크게 줄일 수 있고 좁은 지역은 거의 줄이지 않거나 키울 수 있다. 세로로 긴 요청은 세로로 긴 범위를 자르는 것이며 지형을 세로로 늘이는 것이 아니다. `배율 = 최종 지도 창 폭 / 원본에서 고른 범위 폭`, `창 높이 = 원본 범위 높이 × 같은 배율`로 계산한다. 단위는 먼저 통일한다.
3. 지도·회색 면은 같은 변환으로 움직인다. **8pt 문자·도시 점·지시선은 최종 지도 크기 뒤에 추가**한다. 라벨까지 함께 축소하거나 큰 세계 양식에 8pt 문자를 써 넣고 전체를 줄이지 않는다. 글이 빽빽하면 문자 크기 대신 배치·여백·지리 범위를 조정한다.
4. 지도 선은 최종 출력에서 불투명 검정으로 확인한다. 양식의 선종류와 해안/국경 구분을 유지하고, 작은 지역 확대나 큰 폭 축소로 점선이 실선 덩어리처럼 되거나 사라지면 최종 크기에서 굵기·점선 간격을 조정한다. 기본 바다의 연한 회색·흰 육지·강조 회색이 구별되게 유지한다. 양식의 바다색이 별도 도형이 아니라 대지 배경색(현재 `#EEEEEE`)으로 저장되어 있을 수도 있으므로 작업 대지를 새로 만들 때도 보존한다. JPEG의 불투명 배경 설정을 이유로 의도된 바다색을 흰색으로 바꾸지 않는다.

## 사각형 클리핑

- 작업본에서 ‘내부 경계 점선 합치기’의 잠금을 풀고, **지도 바탕·강조 면 전체와 잘라낼 사각형**을 함께 선택해 `clip`을 적용한다. 마스크 사각형은 선택 대상 중 맨 위에 놓는다. 잠긴 기본 지도가 선택에서 빠져 전체 세계가 밖에 남지 않았는지 확인한다. 보통 최종 배율과 위치를 먼저 맞춘 뒤 클리핑한다.
- 클리핑은 원래 경로를 남기는 편집 가능한 마스크로 만든다. 화면 밖 부분을 삭제하거나 그림을 래스터로 잘라 저장하지 않는다. 대지 크기만 줄여 밖을 숨기는 것으로 클리핑 마스크를 대신하지 않는다.
- 현재 Vectora의 `clip`은 문서 좌표에 고정된 마스크를 만들므로 **클리핑 후 그룹만 이동/축소하면 마스크와 지도가 어긋날 수 있다.** 배율을 바꾸면 지도와 마스크의 변환을 함께 확인하거나 마스크를 다시 적용한다. 클리핑 그룹의 전체 선택 상자가 잘린 지도 창의 크기와 같다고 가정하지 않는다. 대지는 실제 마스크 창과 라벨 외곽을 기준으로 설정한다.
- 마스크와 표시용 테두리는 별개다. 요청/구도상 테두리가 필요하면 별도 검정 선으로 만들고 지도 창과 일치시킨다. 라벨·지시선은 지도 그룹 위의 독립 요소로 두어 바깥 여백에 놓인 문자가 잘리지 않게 한다. 최종 지도 그룹은 필요하면 다시 잠그되 문자 편집은 가능하게 둔다.

## 이 유형의 검사

- 요청 국가·섬만 회색이며 문자/지시선 끝/도시 점의 대상이 맞는가?
- 해안은 실선, 국가 간 내부 경계는 점선이며 실제 축소 크기에서도 구별되는가?
- 요청 범위·종횡비·최종 mm 폭을 지켰고 지형을 찌그러뜨리지 않았는가? 포함해야 할 국가·섬·지시선·문자가 잘리지 않았는가?
- 모든 문자가 상위 그룹 배율까지 포함해 실효 8pt인가? 라벨과 선의 겹침, 강조 면에 가려진 경계가 없는가?
- 편집 가능한 클리핑 마스크·경로·별도 문자가 `.vectora` 재열기 후 유지되는가? 같은 저장본에서 내보낸 JPEG를 실제로 확인했는가? 승인된 원본 양식은 변경되지 않았는가?
