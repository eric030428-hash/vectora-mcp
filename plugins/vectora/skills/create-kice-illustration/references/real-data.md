# 실자료 조사·표시

사용자가 실제 수치·시계열·지역 통계를 시각화하거나 실제 위치 정보·특정 시점의 지리 분포를 조사해 지도에 나타내려 할 때 적용한다. 원자료나 출처가 없으면 아래 기준으로 검색하고, 표·URL을 제공했으면 그 자료를 직접 확인한다. 가상 예시·정성 개형·일반 원화·가상 지도에는 자동 적용하지 않는다. 사용자가 특정 자료를 지정하면 그 출처를 우선 확인한다.

## 수집과 기준 통일

- 국가 통계기관·자료 생산 기관의 원표/API/파일과 신뢰할 수 있는 국제기구의 원자료를 우선한다. 보도·재인용 자료는 원표로 거슬러 올라간다. 검색 결과 요약만으로 값을 확정하지 말고 원문 표·API 응답·파일 내용을 직접 읽어 대조한다.
- 요청한 지역·기간을 빠짐없이 포함하는지 확인한다. 지역 경계, 통계 정의, 단위·분모, 연간/연말 기준, 시계열 기준이 이어지는지 맞춘다. 명확한 통계 관례가 있으면 그 기준을 선택해 기록하고, 자료로 해소할 수 없으며 해석을 바꿀 때만 질문한다.
- 원표 주석으로 집계 시점, 포함·제외 대상과 분모를 확인해 기간 전체에서 같은 통계를 비교하는지 확인한다.
- 기준·경계·분류가 개정된 시계열은 일관된 기준으로 재작성된 공식 계열을 우선한다. 이어 붙일 수 없으면 단절을 표시하고 서로 다른 정의를 한 선으로 연결하지 않는다.
- 잠정·추정·확정 상태를 구별하고, 결측은 0이나 보간값으로 바꾸지 않는다. 원자료를 찾지 못하면 실측 자료처럼 보이는 완성값을 만들지 말고, 확인한 범위와 빠진 부분을 밝힌다. 가독성을 이유로 요청된 지역·연도·관측값을 삭제하지 않는다.

## 가공과 그래프

- 원자료와 그래프 입력값·표시값을 구별하고, 출처의 표/행·기준 연도·단위·확인일, 값별 변환을 작업 기록에 남겨 재현할 수 있게 한다. 기본 납품은 `.vectora`와 JPEG 한 쌍으로 유지하고 출처 파일을 추가 납품하지 않는다.
- 사용자가 형식을 지정하지 않으면 목적에 맞춰 고른다: 시간 변화는 선, 소수 시점·지역 비교는 막대(긴 지명은 가로 막대), 유효한 분모가 있는 구성비는 100% 누적, 두 변수의 관계는 산점도를 우선 검토한다.
- 사용자가 표시 단위·정밀도·형식을 지정하지 않았으면 시험지에서 읽기 쉽게 단위를 환산하고 일관된 자릿수로 반올림하거나 값 라벨을 생략할 수 있다. 단위·축·필요한 눈금·기준 연도·범례는 남기고, 표시값의 정밀도 때문에 순위 역전·의미 있는 차이 소실·0으로 오해·추세 왜곡이 생기면 더 정밀하게 표시하거나 숫자 라벨만 생략한다.
- 라벨 생략은 문자 표시만 줄이는 선택이다. 요청된 연도·지역·관측값과 그래프의 자료점은 그대로 보존한다.
- 입력 좌표는 원자료 그대로 두고 라벨만 반올림하면 `exact`다. 반올림한 자료를 그래프 입력·좌표로 사용하면 그 같은 값을 도형과 라벨에 일관되게 쓰고 근삿값임을 알리며 `approximate`로 기록한다. 제공값의 소수 자릿수는 일반 원칙대로 보존한다.
- 매년 자료라면 모든 관측점을 보존한다. 연도가 빽빽할 때는 축의 연도 표기만 성기게 하며, 자료점이나 요청 기간을 줄이지 않는다. 축 간격은 실제 지원되는 설정·편집으로 조정하고 존재가 확인되지 않은 MCP 라벨 간격 옵션을 가정하지 않는다.
- 구성비의 반올림 오차를 숨기려고 원자료를 몰래 정규화하지 않는다. 원자료와 환산·반올림 규칙, 근삿값 사용 여부를 작업 기록과 최종 설명에 분리해 적는다.

## 지도와 출처 표기

- 검색한 실제 시점·지역·공간 단위와 승인된 지도 경로를 정확히 대응시킨다. 비교 가능한 비율·밀도 등은 판독하기 쉬운 소수 단계 채움(경계값·범례·결측 표기 포함)을 검토하고, 총량은 기호의 면적이 값에 비례하는 표현을 우선 검토한다. 위치 확인과 통계 검증은 따로 한다.
- 도시 점은 신뢰할 수 있는 실제 위치·좌표를 확인하고, 승인된 양식의 투영·등록 기준에 맞게 환산할 수 있는지 검증한다.
- 지도 구간의 범례는 값이 실제로 속하는 경계와 대응시킨다. 누락·해당 없음은 0이나 채움 단계로 합치지 말고 별도 표시한다.
- 국가 경로에 소지역 통계를 억지로 붙이거나 가짜 경계를 만들지 않는다. 지도 파일의 x/y를 위·경도로 보지 말고, 행정 경계 기준 시점이 다를 때 근거 없이 좌표를 왜곡해 맞추지 않는다. 자료 검색은 승인된 지리 바탕을 대체하지 않는다.
- 최종 설명에는 기관·표/데이터셋 이름·기준 연도·단위·가공 요약과 직접 출처 URL을 적는다. 작업 기록에는 확인일·원표 식별정보·원자료와 표시값의 대응을 남긴다. 그림 안 출처는 필요할 때 `자료: 기관(연도), 일부 반올림`처럼 짧게 두며 긴 URL로 가리지 않는다.
