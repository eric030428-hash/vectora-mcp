# 자연 분포·지형·기후

[지도 공통](map-illustrations.md)을 먼저 적용한다.

- 하천·호수·산지·해구·해령·판 경계·기후선은 국경과 별도 자료 및 선종류다. 해령 눈금·단층 상대운동·측정점은 독립 기호로 둔다.
- 분포 주제명이 제공되지 않으면 자연 분포 형태까지만 설명한다. 식생·기후·작물 등으로 이름을 임의 확정하지 않는다.
- 자연 분포는 국가 경계를 가로지를 수 있다. 국가 채움 경로에 억지로 맞추거나 국경을 자연 경계로 대체하지 않는다.
- 등치선은 값·단위·시점·선 간격이 있는 자료를 사용한다. 기후 경계·계절별 수렴대·고도선을 생성 이미지나 임의 곡선으로 꾸며 실제 자료처럼 만들지 않는다.
- 실제 위성/항공영상·밀도 래스터는 원자료 그대로 포함할 수 있다. 범례·캡션·식별 문자는 편집 가능한 벡터로 조판한다.
- 해안 지형 확대는 필요한 상세도, 하천·섬·갯벌 범위와 축척 근거를 확인한다. 저상세 세계 바탕으로 세밀한 해안 유형을 대신하지 않는다.
- 좌표·범위가 등록된 원자료가 없으면 해당 지리 층의 부족 자료를 알린다. 라벨·범례·자료 배치 등 가능한 조판만 진행한다.
- 개념 설명용 자연물 모식도는 실제 분포 지도와 구분하고 삽화/모식도 지침으로 라우팅한다.

- 등록 프리셋의 자연 층은 실제 `roles`를 조회해 선택하고, 추가 자료는 같은 좌표 등록이 확인된 경로 SVG나 실제 포함 영상으로 조판한다. 독립 경로·기호·문자·범례와 바탕 클립을 보존한다.
- raster import는 재투영/warping 기능이 아니다. 등록이 다른 영상을 늘이거나 자르기만 하여 정확히 정합되었다고 보고하지 않는다.

- 판 구조 교체 양식의 해령·수렴·섭입·보존 경계·이동 방향·열점·조산대는 서로 다른 역할이다. 필요한 층만 켜고 원저자·CC BY-SA 출처/변경 표시를 보존한다.
- 빙하 교체 양식의 `ice`는 PaleoMIST **20 ka 모형 빙상**, 유럽 `paleoglacier`는 GLACIMONTIS의 **지역별 최종 빙기 최대 범위**로 동시점 자료가 아니다. 정확히 20 ka만 요구하면 후자는 숨긴다. 해안·국경은 현대 참고선이며 빙기 해안으로 설명하지 않는다. 특정 시기 고해안선 요청에는 별도 시기·좌표가 검증된 자료를 확보한다.
