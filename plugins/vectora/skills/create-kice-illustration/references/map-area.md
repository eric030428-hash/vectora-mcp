# 범주 영역·국가 강조

[지도 공통](map-illustrations.md)을 먼저 적용한다.

- 같은 회색 국가 강조, 서로 다른 명목 범주, 국경과 무관한 산업·문화 등 영역을 구분한다. 농도 차이만으로 수치 등급을 추정하지 않는다.
- 국가 ID와 본토·섬·분리 영역의 대응을 확인한다. 사용자 정의 영역은 제공된 윤곽이나 근거 있는 자료로만 만든다.
- 명목 범주는 채움·선무늬·점무늬와 범례로 구별한다. 중복 범주는 겹침 표현 및 복수 범주 대응을 유지하며 수치 단계로 바꾸지 않는다.
- 현재 production `pattern`은 선택 도형에 점/해칭과 클립을 만들 수 있다. 연결된 스키마를 확인하고 지리 대상 폴리곤을 먼저 식별한다. 무늬는 사용 가능한 편집 경로로 구현한다. SVG pattern 보존을 가정하지 말고 실제 선/점 개체와 마스크 또는 확인된 대안을 쓴다.
- 면 내부 문자와 바깥 인출선을 대상 크기에 따라 선택한다. 복수 분리 영역에 하나의 라벨이면 필요한 여러 인출선을 사용할 수 있다.
- 채움이 해안·국경·작은 섬을 가리지 않게 선 레이어 순서를 확인한다. 인출선과 도시 점은 별개다.

- 무늬 생성 후 source 면·윤곽 복제·marks의 순서를 확인한다. 같은 국가의 여러 섬/분리면은 모두 대응시키고 해당 영역 밖으로 무늬가 새지 않게 한다.
- 범례는 실제 채움/점 간격/해칭 각도와 굵기를 사용한 독립 샘플과 text로 만든다. 범례의 임의 축소로 지도와 다른 무늬 밀도를 만들지 않는다.
