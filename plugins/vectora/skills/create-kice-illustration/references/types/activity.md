# Activity — 학습·활동 텍스트그림

원래 IT3 계열이다. 수업 보드·슬라이드·학습지·활동 양식이 중심이며 교사+말풍선도 한 단위다. 보드 안의 독립된 완결 그래프·표는 별도 복합형 요소다.

| 학습 매체 | 읽을 하위 문서 |
|---|---|
| 학습 화면·슬라이드·보드·교사 발표·카드 게시판 | [board](../subtypes/activity/board.md) |
| 학습 응답·과제·활동 양식 | [worksheet](../subtypes/activity/worksheet.md) |

글을 담는 외피의 연속 흰 공간·장식 분리·팔레트·여백·반복 카드 배치는 SKILL.md의 조건을 적용한다. 제목·지시·내용/빈 응답 영역을 나누고 활동 순서와 영역의 대응을 보존한다. 제공하지 않은 과제 내용을 추가하지 않는다. 작은 작성자 초상 때문에 별도 유형 문서를 읽지 않는다.

내용·활동 순서·실제 연속 예약 치수·마지막 줄과 외피 충돌을 확인한다.
