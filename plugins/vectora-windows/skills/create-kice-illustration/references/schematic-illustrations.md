# 모식도 원칙

**개체와 관계를 먼저 확정하고 그 의미로 배치를 만든다.** 노드(대상·질문·특성·결과·인물)와 연결표(출발·도착·방향·분기 문구)를 현재 요청에서 작성한다. 미지수·빈 질문을 풀어 채우지 않는다.

## 벤 제작 경로

일반적인 2·3집합의 교집합 도식은 앱의 **벤 다이어그램 만들기**와 같은 `vectora_production`의 `kind:"schematic", layout:"venn"`을 개별 원·SVG보다 우선 사용한다. 실행 시에만 [벤 계약](graph-venn-production.md#벤-다이어그램)을 읽는다. 서로 배타적인 영역과 전체 교집합을 구별하며, 원 크기·겹친 면적은 수량에 비례하지 않는다. 완전 포함·서로 분리된 집합·4집합 이상 등 생성기의 고정 교차 배치로 표현할 수 없는 관계는 별도 편집 가능한 도식으로 만든다. 지원되지 않는 관계를 겹치는 원으로 대신하지 않는다.

## 형태와 연결 의미

- 질문·특성은 흰 직사각형, 간단한 대상/결과는 원 또는 직사각형으로 명료하게 구별한다. 같은 역할은 같은 형태·크기를 공유한다. 모든 질문을 일반 흐름도의 마름모로 바꾸지 않는다.
- 특성 대응은 무방향 선, 절차/판정은 방향 화살표, 상호 관계는 의미에 따라 무방향·단방향·양방향을 사용한다. 단지 꾸미려고 화살촉을 추가하지 않는다.
- 선이 교차했다고 접속점을 만들지 않는다. 실제 공유 줄기는 하나의 분기점으로 표현하고, 여러 대상의 공통 특성은 같은 상자에 연결한다. 공통 특성 상자를 불필요하게 복제하지 않는다.
- 여러 질문이 같은 결과를 가리키는 구조와, 앞 응답이 다음 질문으로 이어지는 구조를 구별한다. 각 질문의 모든 응답 경로를 연결표와 대조한다.
- 예/아니요 판정에서는 별도 지정이 없으면 **예=실선, 아니요=파선**으로 일관되게 구분한다. 화살촉은 검정 채움, 선 끝이 아니라 **화살촉 끝**이 도착 윤곽에 닿게 한다. 도형 내부로 들어가지 않는다. 비그래프 파선의 정확한 주기는 내용/크기에 맞춰 정한다.
- 인물 관계도는 [인물 원칙](people.md)을 적용한다. 이름·소속을 인물 가까운 바깥 공간, 관계명·기호를 연결 통로에 둔다. 관계도가 말풍선 대화로 바뀌어서는 안 된다.

## 크기·배치

- 긴 문구는 상자 안에서 실제 조판하고 위아래 여백을 더해 높이를 정한다. 단문 특성 상자는 세로로 두껍지 않은 긴 띠 형태로, 여러 줄 질문은 필요한 만큼 높인다. 문자 중심과 도형 중심을 맞춘다.
- 대상 원은 짧은 글만 담도록 하고 원 지름은 상자 높이와 비슷하거나 약간 크게 둔다. 단문 특성 띠에 연결되는 원은 상자 높이의 **약 1.2–1.6배**를 출발점으로 삼는다. 문장이 여러 줄이면 이 비율을 강제하지 않는다.
- 반복 특성 상자 사이에는 상자 높이의 **약 1/3** 정도를 출발점으로 삼아 리듬을 만든다. 순차 질문 사이의 통로는 분기 라벨과 촉을 수용하는 **약 3–7mm**부터 잡고 실제 문자에 맞춰 조정한다. 단순히 대지를 채우려고 연결 통로를 늘리지 않는다.
- 연결선은 주로 수평·수직 또는 간결한 사선으로 그린다. 출발점·꺾임·도착점을 정렬하고 같은 수준의 가지 길이와 빈 공간을 균형 있게 만든다. 교차를 없애기 위해 관계 의미를 바꾸지 않는다.
- 갈라진 두 경로에서 병렬 역할의 판정과 최종 결과는 각각 같은 높이에 놓는 것을 우선한다. 한 가지의 판정을 너무 위에 두어 결과까지 긴 빈 수직선이 생기면 꺾임 통로와 노드 높이를 함께 조정한다. 범례는 남는 상단 공간에 맞추며 본도식의 단계 간격을 밀어내지 않는다.
- 직각 꺾임 통로는 도형 밖에 예약하고, 라벨과 선 사이에 글 획이 닿지 않는 간격을 둔다. 글을 가리는 선을 흰 사각형으로 임시 가리는 대신 선 경로/라벨 자리를 설계한다.
- 둘 이상의 특성을 묶은 원은 그 묶음의 중심 높이에 놓는다. 여러 질문의 공유 결과는 질문 사이 높이에 놓을 수 있다. 어느 경우도 과거 도형 개수/좌우 배치를 고정 템플릿으로 사용하지 않는다.

## 포함·위계·순환·정성 좌표

- 벤·포함 도식은 교집합·포함·분리의 관계를 먼저 확정한다. 원이 닿거나 겹치는 모양 자체가 의미를 바꾸므로 장식상 중첩하지 않는다. 지정 영역의 해칭·기호는 그 영역 안에 두며, 요청하지 않은 수량을 원 크기나 중첩 면적으로 암시하지 않는다.
- 트리·조직도는 상하 관계와 같은 위계의 정렬을 우선한다. 가지 개수·단계 수를 정형 틀에 맞춰 줄이지 않는다. 순환도에서는 각 흐름의 출발·도착·방향을 따로 검수하고, 여러 종류의 흐름은 선종류와 범례로 구분한다. 곡선·우회선은 순환과 연결을 읽는 데 필요한 경우에 쓴다.
- 정성 좌표는 축 양끝의 의미와 대상의 상대 위치를 보존하고 임의의 수치 눈금을 넣지 않는다. 축 표기는 [그래프의 필수 인쇄 표현](graph-illustrations.md#필수-인쇄-표현)을 적용한다. 세로축 제목을 패널 상단 중앙의 그림 제목처럼 떼어 놓지 않는다. 기준선·이동 방향도 제공된 관계만 표현한다. 실제 수치 좌표나 수량 비례가 있으면 그래프의 해당 자료 유형 원칙도 함께 적용한다.

## 표·행렬

- 먼저 행/열 제목·병합 범위·셀 값·빈칸의 의미를 확정한다. 다단 헤더는 상위 범위와 하위 열을 일치시키고, 병합 셀 내부에만 선을 생략한다. 대각선 헤더는 두 제목을 각 삼각 영역에 온전히 배치한다. 공유 경계는 중복해 긋지 않는다.
- 짧은 항목·기호·헤더는 중앙, 긴 설명은 왼쪽 정렬을 기본으로 한다. 숫자 열은 중앙 또는 오른쪽 중 비교에 맞는 방식 하나를 유지한다. 열 너비는 실제 문구·수치로 정하고, 행 높이는 그 행의 가장 높은 글상자에 위아래 여백을 더한다. 같은 역할의 값 열은 가능한 한 같은 폭을 쓴다.
- 흰 본문과 얇은 검정 격자를 기본으로 하며 헤더·비해당 칸 등 의미 있는 곳에만 회색 면을 쓴다. 미지수·미입력·0·해당 없음·불가능한 조합을 서로 바꾸지 않고, 빈칸을 추측해 회색으로 막거나 채우지 않는다. 제공된 합계·소계는 위치와 구분선으로 식별하게 한다.
- 단위는 해당 표의 우상단 바깥 또는 적용되는 헤더 가까이 둔다. 웹·활동지·칠판 안에 들어가도 셀 격자는 직각으로 유지하고, 외부 장식은 본문 셀을 침범하지 않는다. 매체 배경이 있으면 텍스트일러 원칙도 적용한다.

## 연표·상태 구간

- 사건 순서를 보여 주는 연표와 실제 경과 시간을 재는 축을 구별한다. 순서만 주어졌으면 범주 간격으로 배치할 수 있지만, 경과 시간의 수량 비교에는 실제 시점 간격을 쓴다. 사건·구간 개수와 기호는 입력대로 유지한다.
- 사건 위치의 핀/구분선과 그 사이의 구간 라벨을 구별하고, 사건명은 해당 위치 가까이 줄바꿈해 배치한다. 여러 주체의 상태 구간은 시점 경계를 공유하며 행을 나눈다. 사건 핀을 진행 화살표로 오해하게 하거나, 제공되지 않은 전환·방향·기간을 추가하지 않는다.

## 이 유형의 검사

연결표와 실제 모든 선을 한 개씩 대조한다. 질문 문구·결과 기호·분기 라벨, 방향/무방향, 실선/파선, 교차/접합이 맞는지 확인한다. 표는 셀 대응·병합 범위·빈칸 의미, 연표는 사건 위치·구간 경계, 벤은 포함·중첩을 추가 대조한다. 도형을 이동한 후에는 선·촉·라벨도 다시 맞춘다. 인물이나 관계 기호를 빈 자리표시자로 남기지 않는다.
