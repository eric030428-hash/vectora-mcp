# 위치·점·기호

[지도 공통](map-illustrations.md)을 먼저 적용한다.

- 원·사각·삼각·다른 기호는 위치나 범주를 구별한다. 같은 크기 기호를 근거 없이 수량 비례기호로 해석하지 않는다.
- 점은 등록된 좌표 또는 바탕에서 확인된 위치에 놓는다. 기호 중심과 위치 기준을 일치시킨다.
- 작은 장소를 타원·국지 영역으로 묶을 수 있지만 국가 전체 채움이나 자연 경계와 혼동하지 않게 한다.
- 문자·인출선·기호를 분리하고 필요한 기호 범례만 둔다. 고도 등 부가 수치는 단위와 의미를 명시한다.
- 화살촉 없는 연결선은 지점 묶음·비교·관계일 수 있다. 선이 있다는 이유로 이동 방향을 추측하지 않는다.
- 고정 지리점은 이동하지 않는다. 8pt 라벨은 실제 잉크 경계 상자와 점 외곽 사이에 약 0.7–1.5mm를 기본 간격으로 둔다. 글자가 해안·국경·다른 점과 겹치면 anchor를 유지한 채 작은 오프셋, 짧은 인출선, 최소 흰 halo 중 알맞은 방법을 쓴다. 이 간격은 조판 시작값이며 모든 지도에 강제하지 않는다.

- 현재 기호는 일반 `add`의 ellipse/polygon/path, 문자는 독립 text로 만든다. 이 경로는 경위도 변환을 수행하지 않는다. 문서 anchor인지 등록 좌표인지 구분해 기록한다.
- 문자 위치는 바꾸어도 지점 anchor는 보존한다. 지도 바탕 배율을 바꾼 뒤 기호 크기·인출선·실효 8pt를 다시 확인한다.
