# Paper — 종이 문서·책·대본·자료/인용/정보카드

종이 문서·책·대본과 자료카드·인용문 카드·정보카드를 포함한다. 모서리만 단순하게 처리한 정보상자도 이 하위 유형이며 별도 매체 장식을 요구하지 않는다. 원래 IT2의 `text_box(자료카드·인용문·정보카드)`를 여기로 연결한다. 카드·정보상자는 필요한 최소 윤곽과 제목/본문/출처·작성자 영역만 구성하며 제공된 인용문과 표시를 보존한다. 반복 카드 배치는 부모와 루트의 조건을 적용한다.

종이에는 겹침·접힘·그 아래 작은 그림자, 책/대본에는 표지·책등·제본·겹친 페이지를 필요한 만큼 선택한다. 매체와 무관한 화면 조작부나 모든 형태에 동일한 아이콘을 붙이지 않는다. 전용 배경 helper의 지원 variant가 없으므로 직접 구성한다.

본문과 페이지/접힌 모서리·제본을 분리하고 마지막 줄이 접힘이나 하단 경계에 닿지 않는지 확인한다.

지원 연결본에서는 부모 유형의 현재 제작 계약을 사용한다. 본문과 내부 자료·예약 영역을 구별하고 마지막 줄을 검사한다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
