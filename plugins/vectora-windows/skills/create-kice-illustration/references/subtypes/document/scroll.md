# Scroll — 두루마리

- 두루마리는 얇고 작은 위아래 말이, 나선 단면과 짧은 음영을 사용한다. 본문 길이에 비례해 말이 두께를 키우지 않는다. 종이 양쪽을 말이 끝보다 지나치게 안으로 들이지 않고 확보한 폭을 본문/여백에 돌린다. 말이 전체를 진하게 채우지 않는다.

말이의 나선 단면·작은 안쪽 틈·짧은 접촉 음영으로 구조를 읽히게 한다. 줄어든 말이 공간을 새 장식으로 채우지 않는다.

## 선택 배경 실행

`variant:"scroll"`을 사용한다. 기본 말이가 두껍거나 종이가 좁으면 반환 도형을 조정하고 원래 흰 내용 영역/예약 치수는 최소한 유지한다. 지정 높이가 말이를 포함한 외곽 높이로 해석되지 않게 한다.

## 검사

말이 두께·종이 폭과 마지막 줄/예약 직사각형의 침범을 확인한다.

지원 연결본에서는 부모 유형의 현재 제작 계약을 사용한다. 두루마리 외피 안의 실제 연속 내용 영역을 예약 치수와 대조한다. 미지원이면 기존 편집 가능한 요소로 같은 의미를 보존한다.
