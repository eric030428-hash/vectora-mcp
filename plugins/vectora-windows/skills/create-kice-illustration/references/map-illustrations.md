# 지도 공통 원칙

위치와 공간 분포를 나타내는 지도에 적용한다. 지형 입체도·단면도는 삽화로 분리한다.
[공통 원칙](common.md)과 실제 제작 시 [실행 계약](vectora-contract.md)을 함께 적용한다.

## 정보 역할과 필요한 문서

한 그림은 핵심 판독 정보 primary 하나와 secondary의 조합으로 정한다.
바탕 범위·국경·격자·패널 속성은 정보 유형과 독립이다. 원형 지도라고 곧바로 도법 유형은 아니다.

| 핵심 정보 | 필요한 문서 |
|---|---|
| 점·기호·작은 위치 영역 | [위치](map-location.md) |
| 범주 영역·선택 국가 | [영역](map-area.md) |
| 단계구분·비례기호·지도 내 그래프 | [통계](map-statistics.md) |
| 경로·연결·이동·네트워크 | [흐름](map-flow.md) |
| 자연 분포·지형·하천·등치선 | [자연](map-physical.md) |
| 도법·경위선·방위·시차 자체의 판독 | [투영과 좌표](map-projection.md) |
| 역사적 모식지도 | [역사 모식](map-historical.md) |

secondary도 표현하면 해당 문서를 읽는다. primary와 무관하게 구형/극중심 바탕·곡선 격자·좌표 계산이 있으면 투영과 좌표 문서도 읽는다. 확대 삽입·패널·지도와 차트 결합일 때만 [조판](map-layouts.md)을 추가한다.
지도 양식은 [양식 실행](map-template.md)을 따른다.

## 바탕 선택과 가능 범위

- [world_continents.vectora](../assets/maps/world_continents.vectora)와 library SVG의 경계·수역·기하는 각 바탕의 속성이며 다른 지도에 일반화하지 않는다.
- 이 자산의 기본 국경·수역·기하는 한 양식의 값이다. 다른 지도에 보편 규칙으로 강제하지 않는다.
- 선택 프리셋 출처 확인과 manifest 대조는 [양식 실행](map-template.md)을 따른다.
- 현재는 승인 경로의 강조·국경 표시 변경·수역색·범위 클립, 이름 있는 SVG 경로 가져오기와 일반 벡터 조판을 조합한다. 지리 투영이나 지역 경계 자동 생성이 이미 구현됐다고 가정하지 않는다. `kind:map`이나 `project`를 현재 MCP 옵션으로 쓰지 않는다.
- 실제 위치·분포·통계를 확인할 때 [실자료 조사·표시](real-data.md)를 읽는다. 검수용 기출·관찰 카탈로그·측정표는 생성 의존성으로 사용하지 않는다.

## 지리와 좌표 등록

- 해안·섬·본토·이웃 지역의 지리 정확성을 유지한다. 국가 이름이나 배열 순서만으로 경로를 식별하지 않는다.
- 자료 좌표는 바탕과 **같은 투영 및 좌표 등록**으로 변환한다. 화면 x/y를 위경도로 해석하거나 경위도 점을 임의의 비율로 얹지 않는다.
- 바탕의 도법명이 제공되지 않았고 확정 근거도 없으면 unknown으로 남긴다. 사각 외곽·수평 위선·극중심 외형만으로 특정 도법을 단정하지 않는다.
- 범위 자르기와 투영 변경은 다르다. 투영·중심경도 변경은 등록된 지리 자료를 다시 투영해야 한다. 기존 지도를 늘이거나 회전해 대신하지 않는다.
- 지리 바탕과 강조 면은 동일한 변환, 동일 X/Y 배율을 사용한다. 세로로 긴 범위는 세로로 자르며 지형을 늘이지 않는다.
- 국가/대륙/지역/극/복수 범위와 포함할 섬을 먼저 정한다. 날짜변경선이나 극을 가로지르면 잘림·경로 연결을 확인한다.

## 경계·바다·주제선

- 해안선, 국경선, 행정 경계, 자연·통계 주제선, 격자는 별도 레이어와 스타일이다. 대상 경계가 국가·주·자연 경계인지 먼저 구분한다.
- 국경은 요청과 자료에 맞게 없음/실선/점선을 선택한다. 분쟁·시점·경계 정책을 임의로 보정하거나 강조 국가에 새 테두리를 덧씌워 국경 의미를 바꾸지 않는다.
- 바다는 흰색/연회색 등 요청에 맞게 선택한다. 국가 단독 윤곽의 빈 배경을 바다라고 단정하지 않는다. 해안 stroke를 생략한 면 실루엣도 가능하다.
- 촘촘한 해안·작은 섬은 확대 용도에 맞는 상세도가 필요하다. 저상세 세계 윤곽의 확대만으로 정밀 연안을 완성하지 않는다.
- 필요한 최종 지도 선은 불투명 검정 `#000000`으로 정규화한다. 선 자체 없는 면 실루엣에는 새 해안 stroke를 추가하지 않는다.
- 최종 크기에서 선종류와 면 농도가 구별되게 조정한다. 간격과 굵기를 바꾸더라도 경계의 의미·지리 형상은 유지한다.

## 크기·문자·기호

- 별도 폭 지시가 없으면 라벨까지 포함한 완성 폭은 108mm다. 최종 폭이 지정되면 별도 설명이 없는 한 지시 문자까지 포함한 완성 폭이다. 지도 창과 라벨 여백을 구분해 계산한다.
- 자료 이미지의 px/aspect는 측정값이고 제작 문서의 mm는 출력 지침이다. DPI 없는 이미지 px를 mm로 추정하지 않는다. 실행 단위 변환은 [실행 계약](vectora-contract.md#단위와-렌더)을 따른다.
- 지도 바탕 크기를 정한 뒤 **UND Regular 8pt·자간 -60** 문자를 독립 배치한다. 상위 배율을 포함한 실효 8pt를 유지하며 글이 빽빽하면 여백·배치·범위를 조정한다.
- 원·사각 기호는 지점을 표시한다. 영역 라벨·인출선은 면을 식별한다. 영역 지시선 끝에 도시 점이나 화살촉을 자동으로 붙이지 않는다.
- 작은 대상은 빈 바다/여백의 문자와 짧은 검정 인출선으로 연결한다. 기본 인출선 0.3pt는 조판 기본이며 데이터 주제선의 굵기와 혼동하지 않는다.
- 지도마다 근거 없이 북쪽표·축척·경위선·제목을 자동 장식하지 않는다. 축척은 해당 투영·위치·최종 배율에 근거해야 한다.
- 동일 정보 패널은 가능한 공통 척도를 쓰며, 독립 척도가 필요하면 각각 명시한다. 자세한 조판은 필요한 경우만 조판 문서를 읽는다.

## 편집성 및 검수

- 바탕/수역/해안/국경/주제/기호/문자/범례/클립을 구분해 편집 가능한 레이어·그룹으로 보존한다.
- 실제 통계 래스터·위성영상은 자료 그대로 포함하고 문자·범례를 벡터로 조판할 수 있다. 필요한 외부 자연지도 자료를 확보하며 일반 인물·삽화 imagegen 경로로 대신하지 않는다. 가짜 생성 위성영상·등치선·기후 경계를 실제 자료처럼 만들지 않는다.
- 요청 대상·값·범례·단위·지시선 끝·섬 누락, 좁은 해협과 촘촘한 해안, 겹침, 클립과 테두리를 최종 크기와 확대 화면에서 확인한다.
- 실제 좌표 등록·투영·범위·동일 배율, 경계 의미, 수역색, 8pt, 각 패널 척도를 대조한다. 알 수 없는 지리 정보는 불확실성을 숨기지 않는다.
- 같은 이름의 `.vectora`와 `.jpeg`를 납품한다. `.vectora` 저장 후 재열어 경로·문자·자료 이미지·마스크 보존을 확인하고 같은 저장본에서 JPEG를 내보내 실제 연다. 수행한 생성/저장/재열기/내보내기 상태를 구분해 보고한다.
