# 세로대화

- 순서가 있는 발언, 인물이 많거나 주고받는 대화는 위에서 아래로 쌓는다. 인물은 행 가장자리, 말풍선은 가운데의 넓은 영역이다.
- 본문 중심인 행에서는 말풍선 몸통에 전체 폭의 **약 3/4–4/5**를 먼저 배정하고 나머지에 작은 흉상·꼬리·틈을 둔다. 작은 사각 흉상 칸을 쓰는 인터뷰는 흉상 칸을 **폭 108mm에서 약 8–11mm 정사각형**부터 잡고 말풍선을 더 넓게 쓸 수 있다. 남은 옆 공간을 채우려고 인물을 키우지 않는다. 짧은 발언도 동일 폭으로 강제하지 않는다.
- 인물 크기는 작은 읽기 보조 요소로 정한다. 2줄 이상 발언에서는 **인물과 아래 이름을 합친 높이가 말풍선 몸통 높이와 비슷하거나 더 작게** 들어가는지 먼저 확인한다. 반복 인물은 짧은 행을 기준으로 같은 머리 크기를 유지하며 긴 답변에 맞춰 키우지 않는다. 인물 때문에 말풍선 아래에 큰 빈 띠가 반복되면 인물 칸을 먼저 줄인다. 독립 얼굴 단품의 권장 크기를 세로대화에 그대로 적용하지 않는다.
- **이름은 인물의 왼쪽/오른쪽 또는 아래에 둘 수 있다.** 얼굴·어깨의 빈 옆 공간과 행 높이를 보고 정한다. 같은 화자의 반복에서는 이름 위치도 일관되게 유지하고 다른 화자나 꼬리와 혼동되지 않게 한다.
- **위아래 발언 행은 촘촘하게 배치한다.** 행 높이는 말풍선·인물·이름·꼬리의 실제 보이는 외곽까지 포함해 계산하고, 행 사이 빈 간격은 전체 폭의 **약 1–1.5%**(폭 108mm에서 약 1.1–1.6mm)를 출발점으로 삼는다. 이는 제작 참고값이며 고정 규격은 아니다. 인물 원화의 투명 여백을 행 간격으로 세거나 말풍선과 인물에 여백을 각각 더해 간격을 중복시키지 않는다. 위 행의 말풍선/인물/이름과 아래 행의 요소가 닿지 않는 범위에서 좁히고, 글자 크기·본문 줄간격·말풍선 안쪽 여백을 줄여 행 간격을 대신하지 않는다.
- 좌우 교대는 의무가 아니다. 화자 위치의 일관성과 발언 순서를 먼저 유지한다. 같은 화자가 다시 등장하면 같은 외형과 머리 크기를 사용한다. 긴 답변과 짧은 질문이 함께 있어도 실제 화자가 둘이면 한 발표자로 합치지 않는다.
