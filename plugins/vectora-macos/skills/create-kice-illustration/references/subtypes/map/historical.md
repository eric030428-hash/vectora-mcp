# 역사·개념지도

- 시대·출처·대륙/수역 구분·중심 장소·방위 관습·표기 체계를 확인한다. 현대 해안/국경으로 자동 교체하지 않는다.
- 원형 외해·도식 대륙 분할·중심 지점의 의미 관계를 독립 면/선/문자로 구성한다. 회전된 지명/수역 띠는 의미·읽기 방향을 보존하고 글과 지리 도형을 분리한다.
- 수량에 따른 면적/형상 변형 근거가 없으면 카토그램이라 부르지 않는다. 역사적 왜곡과 수량 인코딩은 다르다. 실제 좌표가 아닌 개념 공간에 정확한 거리·축척·투영 계산/지리 등록을 부여하지 않는다.
- 재현 요청은 사용자 원자료를 확인한다. 새 개념도는 제공 내용 관계로 구성하며 옛 검수 예시를 생성 참조로 불러오지 않는다.
- 실제 역사 경계는 해당 시점의 검증 자료/manifest가 필요하다. 없으면 자료 확보를 진행하고 현대 국가 경로 채움으로 역사 경계를 완성했다고 보고하지 않는다. 빙상의 자연 분포 자체가 핵심이면 physical로 분류한다.
