# 역사·개념지도

- 시대·출처·대륙/수역 구분·중심 장소·방위 관습·표기 체계를 확인한다. 현대 해안/국경으로 자동 교체하지 않는다.
- 원형 외해·도식 대륙 분할·중심 지점의 의미 관계를 독립 면/선/문자로 구성한다. 회전된 지명/수역 띠는 의미·읽기 방향을 보존하고 글과 지리 도형을 분리한다.
- 수량에 따른 면적/형상 변형 근거가 없으면 카토그램이라 부르지 않는다. 역사적 왜곡과 수량 인코딩은 다르다. 실제 좌표가 아닌 개념 공간에 정확한 거리·축척·투영 계산/지리 등록을 부여하지 않는다.
- 재현 요청은 사용자 원자료를 확인한다. 새 개념도는 제공 내용 관계로 구성하며 옛 검수 예시를 생성 참조로 불러오지 않는다.
- 실제 역사 경계·문명 영역은 해당 시점과 표현 목적에 맞는 출처의 윤곽/위치를 검증한다. 현대 지리 바탕의 정확성과 역사 영역의 고증은 별개다. 현대 국가 채움이나 임의의 각진 다각형으로 대체하지 않는다. 자료 기반 개략 범위가 허용되는 요청에만 근사를 명시하고, 정확한 경계 재현에는 근사를 쓰지 않는다. 자료가 없으면 확보를 진행하고 미확인 범위를 남긴다. 빙상의 자연 분포 자체가 핵심이면 physical로 분류한다.

## 한국 지도 적용

한국의 과거 해안·1910년대 유로·고지도식 기호는 기준 시대와 좌표/개념 표현을 먼저 확인한다. 현대 행정 바탕은 명시한 참고층으로만 쓸 수 있으며 과거 경계/유로를 대신하지 않는다. 시대별 실자료가 확보되면 바탕+독립 역사 주제층+문자/범례 틀을 재사용하고 고증이 없는 부분은 미확정으로 남긴다.
