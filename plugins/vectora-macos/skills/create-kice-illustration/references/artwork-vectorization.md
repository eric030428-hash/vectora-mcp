# 원화의 선택적 벡터화

**원화까지 벡터로 납품하라는 요청 또는 그림 내부 경로 편집이 필요할 때만 읽는다.** 기본 원화 배치에는 이 변환이 필요 없다. 원화의 해부·포즈·범위부터 확인하고 다음 중 가능한 경로로 변환한다.

- 연결된 Vectora의 `vectora_trace_image`: 회색조 원화를 색상 모드의 소수 회색 면으로 추적하고, 가져오기의 자동 맞춤 배율을 실제 경계로 확인한다.
- 로컬 프로젝트에는 `canvas`, `imagetracerjs`가 있을 때 다음 도구를 사용할 수 있다. 실행 위치는 해당 패키지를 가진 프로젝트이며 앱 기능을 새로 개발하거나 외부 서비스를 설치하지 않는다.

```sh
node skills/create-kice-illustration/scripts/trace_artwork.mjs <새로_생성한_원화.png> <인물_또는_삽화.svg> --width-mm <그림만의_폭>
```

도구는 원화 여백을 줄이고 바깥 경계에 연결된 흰 배경 면을 제외하며 회색조 면과 검정 윤곽을 각각 편집 가능한 경로로 만든다. 기본 6단계 회색이며 그래프의 지정 6색 규칙과는 다르다. `--colors 3..12`, `--detail 0초과..5`(작을수록 세밀), `--max-px 300..1800`, `--min-path 0..100`으로 조절할 수 있다. `--ink 85`가 기본 검정 윤곽 기준이며 0이면 별도 윤곽 추출을 끈다. 연한 회화에는 0 또는 낮은 기준을 사용하고, 검정 면이 번지면 기준을 낮춘다. 출력 옆 `.trace.json`은 처리 값을 기록할 뿐 시각 품질의 합격 판정이 아니다. 기존 출력은 덮어쓰지 않는다.

1. 눈·코·입·손가락·가느다란 더듬이 등 의미 있는 작은 형태가 남았는지 원화와 **벡터 렌더**를 대조한다. 너무 작은 경로를 제거해 눈이 사라졌다면 해상도/최소 경로를 조정하거나 해당 부위만 다시 그린다.
2. 원화 질감 때문에 경로가 폭증하면 원화의 질감을 단순화하거나 추적 값을 조절한다. 단순 초상에 수천 개의 잡음 조각을 남기지 않는다. 전체 경로 수보다 선택·이동·수정이 가능한지와 윤곽 보존이 우선이다.
3. 인물/사물별로 그룹을 나누고 문자·말풍선과 분리한다. 한 사람이 반복되면 이 완성 그룹을 재사용한다. 필요하면 머리/옷/소품을 따로 묶는다. 벡터화한 대상에는 원화 이미지 참조를 남기지 않는다. 일부 대상만 경로로 수정한 경우에는 다른 원화 이미지 개체를 함께 사용할 수 있다.
4. 그림만 비례 축소하여 예약한 영역에 놓는다. 본문·선 규격까지 함께 축소하지 않는다. 인물 원화의 **흰 바탕까지 포함한 전체 경계**가 말풍선 꼬리와 겹치지 않게 두거나, 불필요한 바깥 흰 면을 제거한다. 배경이 없다고 가정하지 않는다. 인물끼리 머리 크기를 맞추고 여백·시선·꼬리 방향을 다시 확인한다.
5. 실제 Vectora에서 경로 선택, 문자 편집, 저장·재열기와 최종 크기 렌더를 확인한다. 원화가 아름답다는 이유로 벡터 변환의 번짐·누락·거친 윤곽을 합격시키지 않는다.

순수 벡터를 요청받은 결과에 한해 이미지 참조가 없는지 확인한다. 이미지 포함을 허용한 일반 제작에 이 조건을 적용하지 않는다.
