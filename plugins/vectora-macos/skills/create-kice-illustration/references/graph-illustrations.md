# 그래프 원칙

먼저 값·항목·계열·시점·단위·결측을 정리하고 자료에 맞는 표현을 선택한다. 제공되지 않은 통계를 만들거나 수치 없는 개형에 숫자 눈금을 부여하지 않는다. 수치 자료의 축 눈금은 주어진 값의 범위와 척도로 계산한다. 계열과 색/무늬/선/표식의 대응은 그림 전체에서 유지한다.

## 필수 인쇄 표현

- 흰 바탕, 검정 문자. **선은 모두 불투명 #000000**이며 축·개형·보조선·인출선·범례 테두리를 회색으로 약화하지 않는다. **채움 면**의 색은 **#FFFFFF, #EEEEEE, #CCCCCC, #AAAAAA, #666666, #000000**만 사용한다. 개체/상위 그룹은 불투명. 그라디언트·그림자·입체 원·둥근 장식 막대를 넣지 않는다.
- 축 **0.4pt**, 개형 **0.6/0.7/0.8pt 중 하나**, 내부 보조선·인출선·범례 테두리 **0.3pt**. 채운 검정 화살촉에는 별도 외곽선을 덧대지 않는다.

| 파선 역할 | 인쇄 pt 단위 반복 |
|---|---|
| 내부 보조선 | 선 1.5 / 간격 1 |
| 점선 개형, 0.6·0.7pt | 선 2 / 간격 1 |
| 점선 개형, 0.8pt | 선 3 / 간격 1.5 |
| 일점쇄선 개형, 0.6·0.7pt | 선 5 / 간격 1 / 선 1 / 간격 1 |
| 일점쇄선 개형, 0.8pt | 선 6 / 간격 1 / 선 1 / 간격 1 |

- 범례가 필요하면 **흰 사각 상자** 안에 견본과 문구를 정렬한다. 원 조각 안 항목명 또는 선 끝 계열명으로 대응이 충분하면 범례를 생략한다. 견본의 점·선·마커 물리 크기는 본체와 같게 한다.
- 지표 Y축 제목은 축 왼쪽에 **글자가 똑바로 선 세로쓰기**로 둔다. 긴 제목은 의미 단위로 두세 개의 세로 열로 나누어 제목 영역에 맞추며, 제목 한 열의 길이 때문에 자료 영역을 불필요하게 세로로 늘리지 않는다. 짧은 단위 `(%)` 등은 지표명과 구분한다. 원그래프에는 축을 추가하지 않는다.
- 수치 축은 특별한 지정이 없으면 읽기 쉬운 일정 간격의 눈금을 사용한다. 관측값 몇 개를 그대로 불규칙한 축 눈금으로 삼지 않는다. 생략 기호 뒤에도 같은 척도와 눈금 간격을 유지한다. X축 제목은 눈금 아래 별도 줄 또는 축 끝 바깥에 두며, 눈금 숫자 사이에 끼워 넣지 않는다.

## 자료 영역과 여백

전체 폭에서 먼저 제목·눈금·단위·범례·외부 라벨을 제외한다. 남은 영역에 데이터를 계산해 배치한다. 숫자가 겹치면 라벨/범례 위치·높이를 바꾸며 자료점을 옮기거나 글자를 줄이지 않는다. 축·격자·화살표는 정보를 읽는 데 필요한 것만 둔다. 바닥선만으로 충분한 비교에 사방 테두리와 눈금을 자동 추가하지 않는다.

국가·지역명 등 긴 범주 라벨은 **의미 단위의 줄바꿈과 실제 글 폭을 먼저 측정**하고 패널 폭·항목 간격을 정한다. 좁은 칸에 자동 줄바꿈해 이름 끝 한 음절만 다음 줄로 떨구거나, 이웃 항목의 글이 한 문구처럼 붙게 만들지 않는다. 복합형도 옆 도식과 폭을 다시 나눠 라벨을 온전히 읽게 한다. 수치 간 거리를 뜻하지 않는 범주 간격은 필요한 라벨 폭에 맞춰 조정할 수 있으나 시점·수치 축의 실제 간격은 바꾸지 않는다.

같은 의미를 비교하는 패널은 척도와 크기를 공유한다. 패널 사이에는 패널 내부 간격보다 큰 여백을 둔다. 무늬는 불투명 바탕 위에 실제 원/선으로 만들고 경계 안에서 자른다. 외곽선과 공유 경계는 한 번만 그린다.

## 눈금 보조선

- **수치 Y축을 쓰는 꺾은선·산점도·세로 막대/누적 막대는 주요 Y눈금에 맞춘 가로 점선을 기본으로 둔다.** 여러 계열·시점·패널의 높이를 비교할 때 특히 유지하며, 값 라벨이 있다는 이유만으로 생략하지 않는다. 자료 화면·칠판·발표형 안의 그래프도 같다. 여러 막대를 수치로 비교하면서 Y축을 생략하려던 경우에도 공통 눈금과 보조선을 먼저 검토한다. 단일 값/소수 항목의 단순 비교는 바닥선과 값 표시로 충분하면 생략할 수 있다. 사용자의 명시적인 생략 지시는 우선한다.
- 점선은 **불투명 검정 0.3pt, 선 1.5pt / 간격 1pt**로 그린다. 주요 눈금에서 자료 영역의 반대쪽 끝까지만 수평으로 긋고 막대·선·표식·문자보다 뒤에 놓는다. 축·영점 실선·테두리와 겹치는 선은 중복하지 않는다. 패널 간 여백·범례·인물 영역으로 연장하거나 축 생략 구간에 그리지 않는다.
- 작은 패널은 읽기 쉬운 일정 눈금 간격으로 주요 높이 약 3–5개부터 정하고, 모든 작은 눈금까지 촘촘하게 채우지 않는다. 숫자가 주어진 자료의 범위로 척도를 계산하며 수치 없는 수요·공급 개형/정성 좌표에 새 숫자나 전면 격자를 만들지 않는다. 원/도넛에는 보조 격자를 넣지 않는다. 가로 막대는 값 축에 수직인 세로 보조선으로 같은 역할을 수행한다.
- 세로 점선은 특정 시점·X값이나 두 좌표의 대응을 읽어야 할 때만 추가한다. 필요한 점에서 축까지 짧게 내린 인출 보조선과 전체 자료 영역의 격자를 구분한다. 산점도도 기본 가로 점선을 먼저 두고, X좌표 판독에 필요할 때 세로선을 더한다. 계열을 잇는 파선과는 굵기·반복 패턴을 구별한다.

## 막대

- 영점에서 길이를 계산하고 공통 축에서는 값에 비례한다. 0값에 가짜 최소 막대를 넣지 않는다. 값 축을 그리면 최대 막대 끝까지 포함하도록 축 길이를 잡고, 그 바깥의 수치 라벨 공간도 따로 확보한다. 음수·누적·축 절단은 요청의 의미와 축 매핑을 명시해 설계한다.
- 같은 계열/항목의 막대 두께는 일정하게 한다. 묶음 내부 간격보다 묶음 사이 간격을 크게 한다. 가로 묶음의 내부 막대를 붙여도 되며 묶음 사이에는 막대 두께 이상의 여유를 둔다. 떨어진 세로 막대는 막대 폭의 약 **0.5–0.7배** 틈을 시작점으로 삼는다.
- 가로 막대의 항목명은 묶음의 세로 중심, 값 축은 아래에 둔다. 세로 소그림은 각 패널 바닥선과 아래 제목을 맞춘다.
- 대칭 비교는 중앙 항목 열을 한 번만 쓰고 좌우 같은 척도로 바깥쪽으로 뻗는다. 중앙 열을 충분히 비워 막대와 항목명을 분리하고 막대 끝 수치를 일정 간격으로 둔다.
- 누적 막대는 실제 합계 비교와 100% 구성비 비교를 구별한다. 구간 경계를 누적값으로 계산하고 쌓는 순서·범례 대응을 패널 전체에서 유지한다. 100%형의 분모를 확인하며, 작은 구간을 가짜 최소 높이로 키우거나 실제 합계를 같게/다르게 보이도록 바꾸지 않는다.

## 원

- 구성비 비교의 원은 **동일 지름·1:1**. 각도는 비율×360°, 12시부터 같은 계열 순서로 시계 방향. 명시된 다른 순서가 있으면 그것을 따른다.
- 합계 100을 확인한다. 오류·반올림 차이를 몰래 정규화하지 않는다. 0% 조각은 그리지 않고 100%는 완전한 원이다. 면적 자체가 수량을 뜻하는 경우는 구성비와 구별해 별도 계산한다.
- 원 지름을 먼저 고정하지 말고 제목·범례·라벨을 배치한 뒤 결정한다. 원 사이 틈은 원 지름의 **약 1/4–1/2**를 시작점으로 삼고 가운데 범례가 있으면 그 폭과 양쪽 여백을 추가한다. 원의 중심 높이와 제목 기준을 맞춘다.
- 항목명·수치(비율 또는 수량)가 주어진 원/도넛은 **큰 조각 안에 항목명과 수치를 직접 표시**하는 것을 기본으로 한다. 실제 글상자 전체가 경계 안에 들어가야 하며, 좁은 조각만 외부로 옮겨 얇은 인출선으로 연결한다. 몇 % 이하라는 단일 기준으로 결정하지 않는다. 모든 조각을 비운 채 항목·수치를 큰 별도 범례로 옮기지 않는다. 여러 원에 공통인 기호/계열의 범례가 필요한 경우에도 각 원의 수치는 조각 가까이에 남긴다. 라벨·인출선 배치를 먼저 조정해 원과 가까이 묶고, 범례 때문에 전체 높이가 원 지름보다 과도하게 늘어나지 않게 한다.
- 항목명+비율을 쓰면 두 줄을 중심 정렬한다. 점무늬와 글이 겹치면 글 주변의 점만 비우며 다른 조각을 가리는 흰 상자·큰 흰 테두리 글자를 넣지 않는다.
- 도넛을 요청하면 같은 각도 규칙을 적용하고, 안쪽 빈 원·고리·라벨 영역을 각각 확보한다. 가운데에는 제공된 총량·시점 등만 넣는다. 조각 비율과 원 전체가 뜻하는 총량을 혼동하지 않는다.

## 꺾은선·자료점

- 실제 x간격과 선형 y척도로 점을 놓고 직선 구간으로 잇는다. 범주형일 때만 등간격으로 놓는다. 스플라인·추세선·면 채움을 자동 추가하지 않는다. 결측은 0이 아니며 해당 구간을 임의 연결하지 않는다.
- 선을 먼저, 표식을 다음에 그린다. 같은 좌표의 점은 실제로 겹쳐 있어야 한다. 빈 사각형·검정 원 등으로 구분하거나 라벨만 이동하며 데이터 좌표를 벌리지 않는다.
- 음수 포함 축에서 0의 위치를 정확히 계산한다. 시간축을 바닥에 둘 때의 독립 0선과, 0을 통과하는 x축을 구분한다. 분기/연도 같은 계층 라벨과 부호·자릿수를 유지한다.
- 선 끝 계열명이나 점별 수치는 가까이 붙이되 표식·선·축·다른 문자와 겹치지 않게 한다. 끝 라벨이 몰리면 지시선 또는 범례로 전환한다. 마커는 글자 높이보다 작고 서로 같은 시각적 크기를 가진다.
- 소수의 자료점에 값을 표시하는 요청이면 **각 점 가까이에 실제 수치를 붙인다.** 해당 값들을 축 눈금으로 옮기는 것으로 대신하지 않는다. 축 눈금은 척도를, 점 라벨은 관측값을 나타낸다. 이중 축에서는 특히 두 역할을 구분하고, 읽기 쉬운 일정 눈금 간격과 별도 점 라벨을 함께 설계한다.
- 시점 사이의 기간 화살표·괄호는 양끝을 해당 시점과 정확히 정렬한다. 위쪽에 떨어져 있으면 시점에서 이어지는 얇은 파선이나 경계 표식으로 대응을 드러낸다. 인접 기간의 촉·문구가 합쳐지지 않게 하고, 기간 띠와 자료 영역 사이에 불필요하게 큰 빈 공간을 두지 않는다. `(년)` 같은 공통 단위는 축 끝 가까이에 별도로 두며 마지막 시점 문자열에만 붙이지 않는다.
- 평균·상하위 값처럼 연결선 없는 자료는 점만 그린다. 축 생략이 필요하면 생략 구간과 실제 매핑을 명시하고 생략 기호로 드러낸다.

## 산점도·버블·추가 축

- 산점도는 각 점의 중심을 실제 x·y값에 놓고 임의로 잇지 않는다. 계열은 표식 모양과 채움/비움으로 구분한다. 점 라벨은 가까운 빈 방향에 두거나 짧은 인출선으로 연결하며, 가장자리·밀집부에서도 점 좌표를 이동하지 않는다.
- 버블은 중심=x·y, 크기=별도 변수다. 면적/지름 중 무엇이 값에 비례하는지 확인하고 범례에도 같은 변환을 쓴다. 면적 비례라면 반지름은 값의 제곱근에 비례한다. 큰 원 때문에 작은 원·중심·라벨이 가려지거나 잘리지 않게 하되, 가독성을 이유로 수량 비례를 바꾸지 않는다.
- 크기 범례는 값이 지정된 비교 원과 라벨로 구성하고, 겹쳐 배치할 때도 각 원의 윤곽과 수치 대응이 읽히게 한다. 다중 계열·시점을 동시에 표시하면 모양과 채움의 의미를 분리해 범례에 밝힌다. 빈 원=과거 같은 의미를 임의로 부여하지 않는다.
- 사분면 기준·평균선·추세선·이동 화살표는 서로 다른 정보다. 요청된 기준값·관계만 표시하고 추세·회귀·이동 경로를 추측하지 않는다. 수치 없는 높음/낮음·개념 위치는 [모식도](schematic-illustrations.md)의 정성 좌표로 다룬다.
- 이중 축은 요청 자료에 필요할 때만 쓴다. 각 축의 단위·범위·계열 대응을 명시하고 각각 따로 좌표를 계산한다. 두 축을 시각적으로 맞추려고 단위나 척도를 바꾸지 않는다. 같은 단위의 패널 비교에는 앞의 공통 척도 원칙을 유지한다.

지원 형태는 [그래프 도구 계약](graph-builder.md)의 데이터 생성기를 쓸 수 있다. 예시 입력을 복사하지 말고 이번 데이터로 입력을 작성한다. 지원하지 않는 형식은 위 원칙으로 직접 구성한다.

## 이 유형의 검사

데이터·각도·영점·범위·결측·계열 대응과 시각 스타일을 따로 검사한다. 누적 경계·버블 크기 변환·이중 축 매핑이 있으면 수치로 대조한다. 주요 눈금과 보조선의 위치·반복 간격·자료 영역 안 종료·뒤쪽 배치를 확인한다. 모든 비교 패널의 공통 척도·구성비 원 지름, 무늬의 인쇄 밀도, 라벨의 실제 획 간격, 전체 외곽을 확인한다. 정확한 입력 수치/이미지에서 추정한 수치/수치 없는 상대 표현을 구별해 그림 밖에 기록한다.
