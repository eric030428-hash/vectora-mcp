# Photo — 실제 사진·스캔·기존 작품 복제

실제 사진·스캔의 연속 계조/조명과 실물·기존 작품의 시각 표현을 유지한다. 새 선화 재작화는 Illustration이다. 하위 문서는 [default](../subtypes/photo/default.md) 하나다.

## 원본 선택과 출처

- 요청에 제공된 사진이 있으면 그 사진을 우선한다. 별도 지정이 없으면 적합한 실제 원본 이미지를 인터넷에서 찾는 것이 기본이다. AI 합성 이미지를 실제 사진/스캔의 대체물로 생성하지 않는다.
- 박물관·소장 기관·공공 아카이브·공식 제작자 등 원본과 대상을 검증할 수 있는 출처를 우선한다. 검색 썸네일만으로 확정하지 말고 원문 페이지와 실제 이미지를 열어 대상명·작가/기관·촬영/제작 시점·소장품 식별정보 중 관련 항목을 확인한다. 서로 다른 판본/유물을 섞지 않는다.
- 사용 가능한 원본 해상도와 라이선스·이용/재배포 조건·필요한 크레딧을 확인해 출처 URL, 원본/이미지 URL, 대상명과 조건을 제작 기록에 남긴다. 필수 크레딧은 조건에 따라 제공하며 자료에 없는 권리를 추정하지 않는다. 이용 조건 또는 대상 식별이 불확실하면 그 상태를 밝히고 다른 적합한 원본을 찾는다. 검색/이미지 열람 실패를 출처 확인 완료로 보고하지 않는다.

## 재현과 배치

- 실제 원본을 이미지 개체로 유지한다. 가벼운 자르기·기울기/방향 정리·크기 조절에 더해, 사용자 요청 또는 시험 인쇄용 흑백 변환과 가벼운 대비/명암 정규화를 허용한다. 대상의 구조·질감·관계와 의미 있는 밝기 차이를 보존하고 하이라이트/암부를 뭉개지 않는다. 색이 식별 근거인 경우 흑백 변환으로 필요한 구별이 사라지지 않는지 확인한다. 원본에 없는 사물·배경·문양·그림자나 정보가 달라지는 색 효과·과도한 보정·재작화·추적은 금지한다.
- 래스터의 픽셀을 수정할 때는 실제 이미지 편집 도구를 사용하고 변경 범위를 명시한다. 단순 배치 변환과 픽셀 편집을 구별하며 원본을 보존하고 편집 결과를 원본과 대조한다. 이미지 편집을 원본 대신 새 사진을 합성하는 과정으로 바꾸지 않는다.
- 종횡비와 필요한 대상 범위를 보존한다. 원본의 일부를 확대하면 같은 원본 부위를 사용하고 해상도도 확인한다. 스캔의 원문/도안은 실자료로 보존하며 별도 요청한 설명·표시·인출선은 독립 개체로 둔다. 사진 안 기존 문자를 새 편집 문자로 가장하지 않는다.
- 흰 외곽이나 사진 배경은 원본의 일부인지 먼저 판단한다. 불필요한 외곽 정리로 중요한 물체·작품 가장자리·식별 표시를 잘라내지 않는다. 역사적 작품의 손상·표면·명암을 임의 복원하지 않는다.

## 검사

원본과 실제 표시 결과를 대조해 대상·판본·방향·범위·질감·명암을 확인한다. 새 합성 요소가 없고 허용된 가벼운 편집만 적용됐는지, 흑백/대비 변환 뒤에도 식별 특징·의미 있는 계조가 유지되는지, 출처/라이선스 기록과 필요한 크레딧이 있는지 확인한다. 해상도나 출처 검증이 부족하면 그 제한을 명시한다.
