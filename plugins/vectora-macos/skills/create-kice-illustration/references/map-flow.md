# 경로·연결

[지도 공통](map-illustrations.md)을 먼저 적용한다.

- 무방향 지점 묶음·쌍 연결도 이 유형에 포함한다. 연결 자체와 이동 의미를 분리한다.
- 출발·도착·방향·경유·시점·수량이 제공된 범위에서만 경로를 구성한다. 화살촉 없는 선에 이동 방향을 추정하지 않는다.
- 빈 원/채운 원이나 양끝 점의 범례가 방향을 정의하면 그 규약을 그대로 따른다. 양방향 가능은 일방향 화살표로 바꾸지 않는다.
- 단순 관계 직선, 실제 경로, 대권 연결을 구별한다. 투영 없는 임의 곡선을 실제 항로나 최단거리로 설명하지 않는다.
- 이동량은 정의된 굵기 단계 또는 비례 굵기와 범례로 표시한다. 선 굵기 차이가 수량인지 문체인지 확인한다.
- 교차·겹침은 곡률·레이어 순서·라벨 간격으로 해결하고 출발·도착 위치는 보존한다. 화살촉 끝과 기호 중심을 확인한다.
- 날짜변경선 횡단은 등록된 투영으로 분할한다. 화면 양끝 사이를 잘못 가로지르는 긴 선을 만들지 않는다.

- 현재 선/곡선은 일반 path와 끝별 `arrowStart`/`arrowEnd`로 편집한다. 무방향 연결은 촉 없는 선으로 유지하고, 이동 방향이 주어졌을 때만 해당 끝에 촉을 적용한다.
- 승인 바탕과 같은 투영의 검증 경로 SVG는 가져올 수 있다. 현재 MCP가 대권 계산·날짜변경선 분할을 자동 수행한다고 설명하지 않는다.
