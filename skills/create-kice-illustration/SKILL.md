# 평가원 스타일 일러스트 제작

**사용자의 내용과 아래 원칙으로 새로 설계한다.** 과거 평가원 예시 이미지·기출·예시 카탈로그·측정표·예시 입력·완성 템플릿을 찾아보거나 복사·추적하지 않는다. 화풍·구도를 위한 기준 예시를 검색하거나 ‘가까운 예시 ID’를 고르는 단계는 없다. 다만 사용자가 실제 인물명 또는 구체적인 유물·사물명을 명시하면 [이름이 지정된 대상의 참조 검색](references/artwork-production.md#이름이-지정된-대상의-참조-검색)에 따라 인터넷에서 외형을 확인한 뒤 새로 그린다. 사용자가 이번 요청에 준 이미지도 내용·관계·필수 대상의 입력으로 해석하며, 구체적인 원본 재현·동일 인물 재사용을 명시했으면 그 요청 자료를 직접 참고할 수 있다. 이는 과거 평가원 예시 전체를 다시 읽는 예외가 아니다.

인물·삽화는 새로 생성한 원화를 이미지 개체로 배치하는 것을 기본으로 한다. 문자·말풍선·그래프·모식도·레이아웃은 편집 가능한 벡터로 분리한다. 전체가 벡터여야 한다는 요청이나 그림 내부 경로 편집이 필요한 경우에만 원화를 벡터화한다.

## 필요한 문서만 읽기

항상 [공통 원칙](references/common.md)을 읽고, 아래에서 해당 유형의 문서를 추가한다. **복합형 요청은 사용자가 지시한 유형을 빠짐없이 나열하고, 해당하는 모든 유형 문서를 읽은 뒤 제작한다.** 대표 유형 하나만 읽고 나머지를 생략하지 않는다. 각 구성 요소에는 해당 유형의 원칙을, 전체에는 공통 원칙을 적용한다. 사용자 지정 배치·크기를 보존하며 필요한 하위 문서(인물·원화 제작 등)도 읽는다. 요청과 관계없는 유형까지 전부 읽지는 않는다.

| 요청의 핵심 | 읽을 문서 |
|---|---|
| 긴 글을 담는 신문·휴대폰·웹·책·대본 등의 장식 배경 | [텍스트일러](references/text-illustrations.md) |
| 수치·구성비·변화·산점도·버블의 시각화 | [그래프](references/graph-illustrations.md) |
| 대상의 특성·관계선·질문 분기·벤·조직도·표·연표·정성 좌표 | [모식도](references/schematic-illustrations.md) |
| 발언과 화자의 대응: 세로/가로/발표 | [대화](references/dialogue-illustrations.md) + [인물](references/people.md) |
| 얼굴·대화용 인물만 | [인물](references/people.md); 대화 배치 문서는 불필요 |
| 대상·행동·장면 자체를 그림으로 전달 | [삽화](references/freeform-illustrations.md) |
| 지도 | 유형만 확인. 제작 방식에 대한 후속 지침이 필요함 |

인물 관계도에는 모식도+인물, 자료 화면 발표에는 대화+인물+텍스트일러를 적용한다. 화면 안에 그래프까지 요청하면 그래프 문서도 읽는다. 복합형은 부분별 원칙을 모두 검수하고 하나의 완성 그림으로 저장한다. 얼굴이나 말풍선이 있다는 이유만으로 삽화 전체를 정형 대화 틀로 바꾸지 않는다.

분류는 외형보다 정보의 역할로 정한다. 원이라도 구성비는 그래프, 포함·교집합은 모식도다. 자연 지형·생물의 ‘모식도’는 대상의 형태를 전달하는 삽화다. 생성 원화에 별도 벡터 식별 기호·인출선을 조판하며, 자연물 전체를 정형 다각형으로 대체하지 않는다. 지형 입체도·단면도는 위치 분포를 나타내는 지도와 구분한다. 칠판·웹 화면은 글을 담으면 텍스트일러, 발표자가 있으면 대화+인물, 내부 표·도식은 모식도도 읽는다. 복합형에서는 같은 대상의 식별 기호·시점·값을 부분 간 대조하고, 각 자료와 설명의 대응이 읽히도록 가까이 묶는다. 매체 프레임 안의 표·그래프·모식도도 편집 가능한 구조를 유지한다.

## 제작과 완료

1. 현재 요청에서 원문·수치·대상·연결·출력 범위와 사용자가 지정한 파일명 규칙·저장 폴더를 정리한다. 스타일 선택은 스스로 하되 정답이나 필수 데이터를 추측하지 않는다.
2. 글/수치가 들어갈 영역과 인물/장식/연결 통로를 나누고 실제 내용량, 지정한 텍스트 상자 치수 또는 지정 줄 수를 UND 8pt로 측정한 높이로 크기·높이·간격을 계산한다. 본문이 없어도 지정 치수의 빈 공간을 먼저 확보하고 여백과 주변 요소는 바깥에 더한다. 유형 문서의 비례 관계를 적용한다.
3. 실제 제작 시 [Vectora 실행](references/vectora-contract.md)을 읽는다. 지원되는 도구로 제작하거나 작업용 SVG를 작성해 Vectora로 가져온다. 최종 저장·내보내기는 Vectora에서 수행한다. 도구 기본값보다 원칙이 우선한다. 생성 도구는 해당 기능이 필요할 때만 읽는다.
4. 대화·발표·관계도·얼굴 단품의 인물 원화는 [필수 화풍 지시와 승인 검사](references/people.md#이미지-생성에-반드시-전달할-화풍)를 통과한 뒤 배치한다. 실제 최종 크기와 확대 화면에서 공통 검수와 해당 유형의 검수만 수행한다. 대화는 꼬리 형태와 [실제 윤곽 간격](references/dialogue-illustrations.md#인물과-말풍선이-벌어지지-않는-간격)을 따로 검수한다. 발견한 충돌·누락을 고치고 편집 원본을 저장한다. 생성·앱 미리보기·저장·재열기는 실제 수행한 상태대로 구분해 보고한다.

5. [결과 파일과 저장 위치](references/common.md#결과-파일과-저장-위치)에 따라 완성 그림당 같은 이름의 **`.vectora` 1개 + `.jpeg` 1개**를 전달한다. Vectora 파일을 먼저 저장하고, 저장한 최종 문서에서 JPEG를 내보낸다. 대화창에는 그 JPEG를 이미지로 표시하고 `.vectora` 링크를 함께 제공한다.

개발용 자료·과거 예시·시험 제작 결과는 스킬 밖에 보관한다. 이 스킬은 그 자료를 생성 시 참조하지 않는다. 추가 지침은 같은 역할의 원칙 문서 한 곳에 통합하며 예시별 설명 문서를 다시 늘리지 않는다.
