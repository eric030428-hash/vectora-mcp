# 평가원 스타일 일러스트 제작

**사용자의 내용과 아래 원칙으로 새로 설계한다.** 과거 예시 이미지·기출·카탈로그·측정표·예시 입력·완성 템플릿을 찾아보거나 복사·추적하지 않는다. 생성 중 기준 이미지를 검색하거나 ‘가까운 예시 ID’를 고르는 단계는 없다. 사용자가 이번 요청에 준 이미지도 내용·관계·필수 대상의 입력으로만 해석한다. 구체적인 원본 재현·동일 인물 재사용을 명시한 경우에만 그 요청 자료를 직접 참고할 수 있다. 과거 예시 전체를 다시 읽는 예외가 아니다.

인물·삽화는 새로 생성한 원화를 이미지 개체로 배치하는 것을 기본으로 한다. 문자·말풍선·그래프·모식도·레이아웃은 편집 가능한 벡터로 분리한다. 전체가 벡터여야 한다는 요청이나 그림 내부 경로 편집이 필요한 경우에만 원화를 벡터화한다.

## 필요한 문서만 읽기

항상 [공통 원칙](references/common.md)을 읽고, 아래에서 해당 행의 문서만 추가한다. 여러 기능이 독립적으로 결합된 그림은 필요한 유형만 조합한다. 다른 유형을 예비 지식으로 전부 읽지 않는다.

| 요청의 핵심 | 읽을 문서 |
|---|---|
| 긴 글을 담는 신문·휴대폰·웹·책·대본 등의 장식 배경 | [텍스트일러](references/text-illustrations.md) |
| 수치·구성비·변화의 시각화 | [그래프](references/graph-illustrations.md) |
| 대상의 특성·관계선·질문 분기 | [모식도](references/schematic-illustrations.md) |
| 발언과 화자의 대응: 세로/가로/발표 | [대화](references/dialogue-illustrations.md) + [인물](references/people.md) |
| 얼굴·대화용 인물만 | [인물](references/people.md); 대화 배치 문서는 불필요 |
| 대상·행동·장면 자체를 그림으로 전달 | [삽화](references/freeform-illustrations.md) |
| 지도 | 유형만 확인. 제작 방식에 대한 후속 지침이 필요함 |

인물 관계도에는 모식도+인물, 자료 화면 발표에는 대화+인물+텍스트일러를 적용한다. 얼굴이나 말풍선이 있다는 이유만으로 삽화 전체를 정형 대화 틀로 바꾸지 않는다.

## 제작과 완료

1. 현재 요청에서 원문·수치·대상·연결·출력 범위를 정리한다. 스타일 선택은 스스로 하되 정답이나 필수 데이터를 추측하지 않는다.
2. 글/수치가 들어갈 영역과 인물/장식/연결 통로를 나누고 실제 내용량, 지정한 텍스트 상자 치수 또는 지정 줄 수를 UND 8pt로 측정한 높이로 크기·높이·간격을 계산한다. 본문이 없어도 지정 치수의 빈 공간을 먼저 확보하고 여백과 주변 요소는 바깥에 더한다. 유형 문서의 비례 관계를 적용한다.
3. 실제 제작 시 [Vectora 실행](references/vectora-contract.md)을 읽는다. 지원되는 도구 또는 직접 SVG 작성으로 완성한다. 도구 기본값보다 원칙이 우선한다. 생성 도구는 해당 기능이 필요할 때만 읽는다.
4. 대화·발표·관계도·얼굴 단품의 인물 원화는 [필수 화풍 지시와 승인 검사](references/people.md#이미지-생성에-반드시-전달할-화풍)를 통과한 뒤 배치한다. 실제 최종 크기와 확대 화면에서 공통 검수와 해당 유형의 검수만 수행한다. 대화는 꼬리 형태와 [실제 윤곽 간격](references/dialogue-illustrations.md#인물과-말풍선이-벌어지지-않는-간격)을 따로 검수한다. 발견한 충돌·누락을 고치고 편집 원본을 저장한다. 생성·앱 미리보기·저장·재열기는 실제 수행한 상태대로 구분해 보고한다.

개발용 자료·과거 예시·시험 제작 결과는 스킬 밖에 보관한다. 이 스킬은 그 자료를 생성 시 참조하지 않는다. 추가 지침은 같은 역할의 원칙 문서 한 곳에 통합하며 예시별 설명 문서를 다시 늘리지 않는다.
