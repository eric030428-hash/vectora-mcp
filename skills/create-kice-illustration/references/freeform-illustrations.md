# 삽화 원칙

사용자가 묘사한 대상·행동·공간 자체를 전달한다. 장면에 맞는 회색조 원화 또는 벡터로 새로 그리며 고정 포즈·대상 목록·하위 유형에 끼워 맞추지 않는다.

자유로운 인물·생물·자연물의 실제 제작은 [원화 제작과 배치](artwork-production.md)을 따른다. 문구와 정형 도형은 원화와 분리한다.

## 화풍

- **검정·흰색·회색만** 사용한다. 그래프의 6색/일률적인 획 굵기를 적용하지 않는다. 같은 장면 안에서 윤곽선의 성격·명암 밀도를 일관되게 유지한다.
- 일반 장면은 또렷하되 과하게 굵지 않은 외곽, 더 가는 내부 묘사, 제한된 회색 명암으로 표현한다. 사진 피부 질감·광택 렌더·장식 효과보다 대상의 특징과 행동이 먼저 읽혀야 한다.
- 나중에 직접 그려 넣는 소품의 윤곽·망·세부선도 인물/주대상의 선 밀도와 맞춘다. 소품이 작은데 테두리나 격자만 검정 덩어리처럼 두꺼워지면 최종 물리 굵기와 배율을 확인한다. 잔상은 주된 물체보다 옅게 하고 동일한 형태·크기를 유지한다.
- 만화적 비유에는 단순한 비례와 명확한 표정, 생물에는 식별되는 구조, 운동 인물에는 자연스러운 관절/무게중심, 풍경에는 넓은 면과 낮은 대비의 질감을 선택한다. 모두를 이모지·아이콘·기하 도형 몇 개로 줄이지 않는다.
- 생물의 몸통·관절·다리는 부피 변화와 점점 가늘어지는 끝을 가진 유기적인 윤곽으로 잇는다. 머리를 완전한 원, 몸통을 캡슐로 연결한 기계 조립도처럼 만들지 않는다. 날개·털·잎맥 등은 큰 구조에 맞는 방향으로 놓고 획 길이·밀도·끝을 조절한다.
- 머리카락·옷주름·날개·꽃잎·물건의 구조를 식별할 만큼 그린다. 미세한 획을 많이 넣는 것으로 세부 완성을 대신하지 않는다. 원화를 그대로 사용하는 회화풍은 연한 윤곽·끊긴 선·명암 면을 사용할 수 있고 원화 픽셀의 검정 외곽을 의무화하지 않는다. 별도로 작성하는 벡터 윤곽선은 [공통 선 색상](common.md#선-색상)을 따른다. 회색 명암 면은 허용한다.

## 구도와 크기

- 핵심 대상/행동이 가장 큰 시각적 비중을 가지게 하고 배경·소품은 의미를 보완한다. 제목·말풍선은 필요한 경우에만 공간을 예약한다. 실루엣→앞뒤 겹침→명암→세부 순서로 만든다.
- 작은 물체는 작게, 전신 동작은 움직임 방향의 빈 공간까지 포함해 전체 크기를 정한다. 108mm는 상한이다. 짧은 변에 맞추려고 피사체를 찌그러뜨리지 않는다.
- 손과 물건의 접촉, 시선 목표, 화면 안/밖, 앞/뒤를 보존한다. 사각 경계의 겹침이 있어도 실제 윤곽과 의도된 앞뒤 관계가 읽히면 허용한다. 중요한 손동작·얼굴·확대 부위가 가려지지 않게 한다.
- 흰 배경은 필수가 아니다. 물·실내·화면처럼 장면을 이루는 배경은 회색 면으로 남긴다. 공간 깊이를 보이려는 크기 차이를 인물 크기 불일치로 일괄 교정하지 않는다.

## 부분 확대·동작·복합 장면

- 부분 확대는 같은 대상의 특정 부위다. 확대 내부의 형태·방향과 연결선이 원래 부위에 대응해야 한다. 원/틀 크기는 필요한 상세가 읽히도록 정하고 본체 옆 빈 공간에 놓는다. 배율·종명·기관 기능은 요청 없이 추가하지 않는다. 자연물의 톱니·털·가시 같은 미세 구조를 동일한 큰 삼각형의 반복으로 도식화하지 않는다. 가늘어진 끝, 짧고 긴 세부와 본체의 연결을 보여 주되 정체가 불확실한 해부 구조를 새로 지어내지는 않는다.
- 잔상은 같은 물체를 위치·회전·농담으로 반복한 것이다. 형태를 유지하고 실제 개체와 시간상 반복을 구별한다. 궤적 방향의 여백을 잘라내지 않는다. 속도·시간·힘·번호·화살표를 자동으로 덧붙이지 않는다.
- 화면 속 장면과 바깥 관찰자, 기계의 입력과 출력, 물건과 그것을 받는 손은 별도 역할이다. 대사를 넣어도 장면을 정형 가로대화로 펴지 않는다. 별도 발언의 조판·화자 대응이 필요할 때만 대화 원칙을 추가 적용한다.
- 회화풍 질감·생물의 세부·동작 장면은 생성 원화를 그대로 사용해도 된다. 불필요한 추적으로 질감을 훼손하거나 수만 개 경로를 만들지 않는다. 원화 속에 별도로 조판할 문자·말풍선·자료 도형을 섞지 않고 실제 편집기에서 이미지와 벡터의 배치 보존을 확인한다.

## 이 유형의 검사

대상 수·구조·손과 물건·시선·확대 대응·잔상의 동일성이 맞는지 본다. 핵심 특징이 최종 크기에서 읽히고 회색조 화풍이 일관적인지 확인한다. 단순 도식/임시 선화만 만든 상태를 완성 삽화로 보고하지 않는다. 그림 안 글자에는 공통 문자 규격을 적용한다.
