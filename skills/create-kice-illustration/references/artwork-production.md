# 원화 제작과 배치

인물·삽화에만 적용한다. **현재 요청으로 원화를 새로 생성하고 이미지 그대로 배치하는 것이 기본이다.** 과거 예시나 테스트 그림은 생성 입력으로 사용하지 않는다. 문자·말풍선·그래프·모식도·장식 틀은 별도 벡터로 조판한다.

## 원화 만들기

- 생성 도구에는 대상·행동·시점과 해당 유형의 화풍·인물 범위를 전달한다. 대화·발표·관계도·얼굴 단품의 인물에는 [인물의 필수 화풍 블록](people.md#이미지-생성에-반드시-전달할-화풍)을 매 호출에 포함하고 같은 문서의 원화 승인 검사를 거친다. 자유 삽화는 [삽화의 화풍](freeform-illustrations.md#화풍)을 적용한다. 큰 외형·원근·관절·겹침이 읽혀야 하며 반복 얼굴 부품이나 장식 문양으로 자연물을 대신하지 않는다.
- 원화에는 별도로 조판할 문자·숫자·말풍선·범례·테두리 레이아웃을 넣지 않는다. 원문과 수치는 살아 있는 문자로 남긴다. 추적을 위한 단순화·색 양자화·회색 단계 축소를 원화에 강제하지 않는다. 화풍과 명암은 인물/삽화 원칙을 따른다.
- 인물 단품은 배치하기 쉽도록 **바깥 배경이 투명한 PNG**를 우선 요청한다. 흰 피부·흰옷은 불투명하게 유지한다. 이미 흰 배경 원화가 있으면 불필요하게 다시 만들지 말고 여백을 정리하고 배치로 간섭을 피한다. 실제 배경 제거/이미지 수정이 필요하면 이미지 편집 도구를 사용한다.
- 자유 삽화는 물·실내·화면 등 장면에 필요한 배경을 유지할 수 있다. 하나의 완결된 장면은 한 이미지 개체여도 된다. 나중에 독립적으로 옮길 인물·소품은 분리 가능한 원화로 만든다.
- 얼굴만 요청하면 머리 범위로, 세로대화용 인물은 어깨~가슴까지 만든다. 발표용은 [발표 배치 순서](dialogue-illustrations.md#발표)에 따라 말풍선 크기와 남은 인물 영역을 먼저 정한 뒤, 최소 어깨~가슴을 포함하는 적절한 신체 범위로 생성한다. 동일 화자의 반복에는 같은 원화를 재사용하고 새로운 화자에게 같은 얼굴을 복제하지 않는다.

## 크기와 배치

1. 본문과 도형을 먼저 조판하거나 지정된 텍스트 상자 크기를 예약하고 그림 영역을 잡는다. **보이는 머리/몸의 경계**로 크기를 맞춘다. 원화 파일의 빈 여백이나 소품까지 포함한 전체 크기로 인물 머리를 맞추지 않는다.
2. 종횡비를 유지해 원하는 크기와 위치에 배치한다. 원본 픽셀을 불필요하게 재샘플링하지 않는다. 배치 개체의 변환과 필요한 자르기 영역을 사용하고 머리·손·꼬리·동작 범위를 자르지 않는다. 본문과 선까지 함께 축소하지 않는다.
3. 인쇄 크기에서 해상도를 확인한다. 실효 ppi는 **사용되는 원화 픽셀 수 ÷ (배치 길이 mm / 25.4)**다. 300ppi 이상을 시작 기준으로, 가는 선이나 확대도는 600ppi 정도를 우선 검토한다. 이는 제작 권장값이며 공식 평가원 규격이 아니다. 단순 픽셀 확대는 세부를 복원하지 않으므로 부족하면 더 큰 원화를 생성하거나 배치 크기를 조정한다.
4. 인물의 배경 사각형·투명 여백과 실제 실루엣을 구별한다. 흰 배경이 말풍선 꼬리나 다른 인물을 가리지 않는지 최종 합성에서 확인한다. 시선·화자 이름·꼬리 방향·머리 크기는 기존 대화/인물 규칙을 그대로 따른다.
5. 확대도는 **같은 원화의 해당 부위**를 사용하고 확대 후 해상도도 확인한다. 잔상은 같은 물체의 이미지 또는 벡터를 회전·이동·농담으로 반복하며 불필요한 원화 변환을 하지 않는다.

## 저장과 검수

- 인물·삽화마다 이름이 있는 이미지 개체로 두어 이동·비례 크기 조절·교체가 가능하게 한다. 그림 내부 눈·코·머리카락까지 경로 편집이 가능할 필요는 없다.
- SVG에는 PNG/JPEG를 `<image>`의 데이터 URI로 포함하거나 실제 앱의 이미지 배치 기능을 사용한다. 최종 SVG/작업 파일이 임시 원화 경로에 의존해 나중에 그림을 잃지 않도록 저장·재열기에서 포함 여부를 확인한다. 원본 PNG도 별도로 보관한다.
- 최종 결과는 **원화 이미지와 편집 가능한 벡터 조판을 함께 사용한 파일**이라고 보고한다. 전체 레이아웃이나 글까지 한 장의 래스터로 합치지 않는다. 인물/삽화만 요청받으면 원화 PNG와 요청받은 편집 배치 파일을 전달한다.
- 실제 크기와 확대 렌더에서 화풍·해상도·흰 배경 간섭·잘림을 확인한다. 실제 편집기에서 이미지 선택/이동/크기와 문자 편집, 저장·재열기 후 이미지·배치 보존을 검사한다.

## 벡터화가 필요한 경우만

사용자가 순수 벡터를 요구하거나 그림 내부 경로를 수정해야 한다면 [선택적 벡터화](artwork-vectorization.md)를 읽는다. 기본 배치 작업에 추적 단계를 추가하지 않는다. 원화를 유지해도 기존의 화풍·비례·내용 검수는 동일하다.
