# 통계 지도

[지도 공통](map-illustrations.md)과 실제 자료일 때 [실자료](real-data.md)를 적용한다.

- 공간 단위·시점·값·단위·결측을 먼저 맞춘다. 국가 값과 행정구역 값을 혼용하지 않는다.
- 비율·밀도의 단계구분은 경계값/포함 조건과 순서 있는 농도를 명시한다. 값 없는 지역을 최저 등급으로 칠하지 않는다.
- 단위점은 점 하나당 수량을 범례에 명시하며 실제 도시 위치점과 구별한다. 자료 해상도 이상의 위치 정확도를 주장하지 않는다.
- 등급 기호는 구간별 원 크기·명도와 범례를 그대로 대응시킨다. 세 등급 원을 연속 면적비례 원으로 바꾸지 않는다.
- 순위 상위/하위 범주 채움은 서열 통계로 취급하고 지표명이 없으면 임의로 채우지 않는다.
- 래스터 명암 방향은 지표별로 확인한다. 인구밀도의 검정=높음과 야간 빛의 흰색=많음처럼 서로 반대일 수 있다.
- 총량 비례 원은 면적을 값에 대응시킨다. 최소 기호·0·음수·결측 처리와 범례 크기를 설명하고 범례도 같은 변환을 쓴다.
- 명목 범주·중복 해칭 자체가 주 정보이면 영역 문서를 우선하고 통계 표현이 필요한 부분만 이 원칙을 추가한다.
- 통계 래스터는 원자료를 그대로 배치하고 단위·농도 방향·범례를 보존한다. 행정 경계가 없으면 국가 경로로 소지역 값을 대신하지 않는다.
- 지도 내 그래프는 [그래프](graph-illustrations.md)와 실제 제작 시 [그래프 실행](graph-venn-production.md)을 읽는다. native 생성기로 수치·축·점·기본 서식을 최대한 만들고 누락 기능만 독립 개체로 보완한다.
- 여러 패널의 등급·원 크기·차트 축은 비교 목적에 맞게 공통화하거나 차이를 명시한다. 지도 범위 차이로 통계 의미가 바뀌지 않게 한다.
- 현재 범례·문자·도형 조판과 이미 존재하는 경로 채움은 가능하다. 자동 데이터 join·단계구분·지리별 기호 생성이 현재 지도 API라고 주장하지 않는다.
