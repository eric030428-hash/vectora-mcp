# Board — 학습 화면·보드·교사 발표

학습 화면·슬라이드·칠판·게시판을 제작한다. 보드·핀·받침·조작부는 매체에 필요한 요소만 선택한다. 교사와 말풍선은 같은 단위로 구성하며 Dialogue/Document 문서를 추가로 읽지 않는다.

## 교사·발표자가 있는 경우

- 학습 면의 내용과 교사의 실제 발언을 분리하고 발언이 자료를 가리지 않게 한다. 화자 ID와 발언을 연결하며 화면의 이름을 새 화자로 세지 않는다. 말풍선 형상·실제 윤곽 수치 간격·인물 화풍은 SKILL.md의 조건부 공통을 적용한다.
- 큰 말풍선이 중심이면 몸통 치수를 먼저 확정하고 남은 폭에 교사·바깥 이름·꼬리·간격을 예약한 뒤 그 좁고 긴 영역에 맞는 인물을 생성한다. 말풍선 폭 약 70–80%는 초기 참고값일 뿐 지정 내용 영역이 우선이다. 보이는 인물 높이와 하단은 말풍선 몸통과 비슷하게 맞춘다.
- 큰 화면 옆 교사와 위쪽의 짧은 보조 말풍선이면 화면이 인물 높이 기준이다. 머리는 꼬리 가까이, 인물 하단은 화면 하단 가까이에 둔다. 작은 흉상이 위에 뜨고 아래만 크게 비지 않게 한다.
- 목표 높이·가용 폭·종횡비·좌우 위치를 생성 전에 전달한다. 최소 어깨~가슴, 높은 면에는 필요하면 허리 아래까지 설계한다. 종횡비를 유지하며 크기가 안 맞으면 자세/신체 범위를 다시 설계한다. 기존 흉상 확대·가로 압축·세로 늘이기·투명 여백·연단으로 높이를 채우지 않는다.
- 받은 이름은 인물 바깥쪽 얼굴~어깨 옆에 별도 문자로 둔다(오른쪽 인물이면 오른쪽, 왼쪽이면 왼쪽). 이름 폭/틈도 미리 예약한다. 아래나 말풍선과 인물 사이에 자동 배치하지 않는다. 연단·마이크·손짓은 내용상 필요한 경우만 둔다.

## 선택 게시판 실행

스킬 루트에서 `node scripts/build_text_frame.mjs --spec <입력.json> --output <배경.svg>` 또는 `buildTextFrame(spec)`을 사용한다. 게시판은 `variant:"noticeboard"`, `widthMm` 기본 108/범위 30–108, 필수 `contentHeightMm`은 실제 측정/지정 내용 높이, `paddingMm`은 밖에 더하는 여백이다. 필요에 따라 `columns`, `cardTitleHeightMm`, `footerHeightMm`, `portraitMm`, `headerHeightMm`, `titleHeightMm`을 사용한다. 기존 출력은 명시적 `--force`일 때만 교체한다.

반환 `{svg,layout}`의 `layout.slots`는 문서 px 좌표의 chrome/title/content/author 자리다. 실제 높이에 맞는 `textAlign`/`verticalAlign`을 적용하고 빈 `illustrationSlots`는 요청한 초상으로 채운다. 배경 도구는 본문과 줄 수를 측정/작성하지 않으며 미지원 `lineCount`/`contentWidthMm`을 입력하지 않는다. 실제 슬롯 폭과 연속 직사각형 높이를 확인하고 교사·말풍선은 별도 개체로 배치한다. 다른 학습 매체는 위 원리로 직접 구성한다.


3카드 게시판을 요청하면 `columns:3`으로 구성하며 다른 카드 수를 받으면 그 수를 따른다. 카드 제목·본문·하단 작성자/초상을 각각 예약한다. 생성된 빈 초상 슬롯은 실제 요청된 초상만 채운다.

## 검사

화면과 발언 대응, 꼬리 형상/실제 윤곽 간격, 바깥 이름·높이 기준·하단 정렬을 확인한다. 게시판이면 카드 간격·작성자 대응·예약 공간을 함께 검사한다.
