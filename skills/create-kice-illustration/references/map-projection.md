# 투영·경위선·방위·시간

[지도 공통](map-illustrations.md)의 좌표 등록과 바탕 선택을 적용한다.
primary가 다른 유형이어도 구형/극중심 바탕, 곡선 격자, 투영·좌표 계산을 쓰면 이 문서를 추가로 읽는다.

- 도법 이름은 제공된 자료나 확정 근거가 있을 때만 쓴다. 원형 외곽·북극 중심·곡선 격자는 관찰 기하이며 특정 도법명과 동의어가 아니다.
- 투영·중심경도·회전·범위·날짜변경선 처리·극 clipping을 바탕과 모든 overlay에 동일 적용한다.
- 경위선은 없음/일부/전체를 필요에 맞게 선택한다. 가장자리 위도 눈금만 있는 지도에 전체 격자를 자동 추가하지 않는다.
- 위선·경선·방사선·동심원·적도 외곽은 실제 투영 관계에 근거한다. 지도 테두리가 적도라는 근거 없이 그렇게 설명하지 않는다.
- 시차와 업무 시간은 기준 도시/경도·날짜·서머타임 적용 여부를 확인하고 원호·시각 눈금·선종류 범례를 분리한다.
- 방위·거리·면적 계산은 해당 투영의 성질과 측정 근거를 확인한다. 화면 거리나 원형 외관만으로 지리적 등거리·등면적을 주장하지 않는다.
- 맞는 승인 바탕·투영 엔진이 없으면 필요한 자료/기능을 알리고 가능한 조판을 준비한다. 일반 SVG 자르기나 그룹 회전은 새 투영의 대체가 아니다.

- manifest에 도법·중심·범위가 검증된 고정 SVG 바탕이 있으면 그 좌표 그대로 가져와 조판할 수 있다. 이는 앱의 새 projection API 지원이 아니다.
- 외부 변환 수단은 실제 존재하는 helper와 확인된 입력/출력 계약만 사용한다. 아직 통합되지 않은 planner·projection ID·등록 API를 호출 지침에 넣지 않는다.
