# 역사·개념지도

[지도 공통](map-illustrations.md)을 적용하되 개념 공간과 실제 지리 좌표를 구분한다.

- 시대·출처·대륙/수역 구분·중심 장소·방위 관습과 표기 체계를 확인한다. 현대 해안·국경으로 자동 교체하지 않는다.
- 원형 외해, 도식적 대륙 분할, 중심 지점처럼 의미 있는 관계를 편집 가능한 면·선·문자로 구성한다.
- 회전된 지명이나 수역 띠 표기는 의미·읽기 방향을 확인하고 문자와 지리 도형을 분리한다.
- 수량에 따른 면적/형상 변형 근거가 없으면 카토그램이라고 부르지 않는다. 역사적 왜곡과 수량 인코딩은 다르다.
- 원자료 재현을 요청받으면 사용자 제공 자료를 확인한다. 새 개념 그림은 내용 관계를 받아 구성하며 과거 검수 예시를 생성 참조로 불러오지 않는다.
- 실제 좌표 기반이 아닌 경우 정확한 거리·축척·투영 계산을 자동 부여하지 않는다.

- 실제 역사 경계는 해당 시점의 검증 자료와 manifest가 필요하다. 없으면 자료 확보를 진행하고, 현대 국가 경로 채움으로 실제 역사 경계를 완성했다고 보고하지 않는다.
- 개념도는 일반 path·면·문자를 독립 편집 가능한 상태로 조판할 수 있다. 개념 공간을 실제 지리 좌표로 등록했다는 설명은 붙이지 않는다.
