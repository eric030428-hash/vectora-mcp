# 지도 조판 추가 기능

확대 삽입·여러 패널·지도+차트 요청일 때만 읽는다. primary 정보 유형을 대신하지 않는다.
크기·8pt·좌표·검수는 [지도 공통](map-illustrations.md)에 따른다.

- 현재 production `magnify`는 문서 좌표 범위를 복제하는 원형 확대 조판이다. 지리 LOD나 새 투영을 자동 생성하지 않는다. 사각 패널은 일반 경로·클립·그룹으로 조립한다.
- inset은 원범위 상자와 확대 창을 연결한다. 연결선/확대 화살표는 이동 경로와 구별하고 확대 창의 바탕·좌표·축척을 별도 등록한다.
- 패널별 지도 창·mask·배율과 고정 크기 문자를 분리한다. 지도만 확대해도 문자와 범례를 함께 늘이지 않는다.
- 동일 정보 비교는 공통 척도·통계 등급·범례를 우선한다. 세밀한 지역 확대 등 독립 척도가 필요하면 각 패널에 그 근거를 표시한다.
- 원형 두 반구나 극중심 패널도 같은 조판 체계로 다루되 창마다 필요한 투영 조건을 확인한다.
- 지도+차트는 그래프 native 생성기를 최대한 사용하고 미지원 표현만 추가한다. 범례·기호·단위·자료 시점과 패널의 대응을 확인한다.
- 웹/자료 화면 프레임은 [텍스트일러](text-illustrations.md), 행·열 비교표는 [모식도](schematic-illustrations.md)를 함께 읽는다. 국가 지도·통계 래스터가 표 안에 있으면 지도 및 통계 지침도 모두 적용한다.
- 사진/통계 래스터를 포함한 표에서 명암 방향·축척·국가별 단위가 다르면 각 셀에 명시한다. 프레임 장식과 지도 경계를 섞지 않는다.
- 패널 그룹/개별 레이어/라벨/범례/원자료 이미지를 독립 편집 가능하게 저장한다. 잘린 프레임 조각을 근거 없이 추가 패널로 해석하지 않는다.
